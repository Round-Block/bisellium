# Choose a licence

W-019 (repo hygiene) built everything a licence choice needs — `CONTRIBUTING.md`,
CI, the docs registry — except the choice itself, which is a judgment, not a
mechanical default. No `LICENSE` file exists yet. Options:

- **MIT** — permissive, minimal friction for anyone to use, modify or
  redistribute; no protection against a closed-source fork.
- **Apache-2.0** — permissive like MIT, plus an explicit patent grant and
  contribution terms; slightly more text for a user to read.
- **Proprietary** — no public licence; all rights reserved. Fits a product
  not yet meant for outside use or contribution.

Please pick one (or name another). Once decided, add `LICENSE` at the repo
root and reference it in `README.md` — outside this opus's scope.
