## Intent

Scope items:

1. Verdict logs carry findings, not transcripts. To be set at spec time.
2. `ci/` gains a retention rule. To be set at spec time.
3. Record-only commits stop costing a CI round-trip. To be set at spec time.
4. **CI runs the contained-builder live rows** (Patron, 2026-10-04: "fold it
   into w131").
   - Problem: CI skips 26 of the 38 tests in
     `packages/commands/src/run.test.ts` with "bwrap is unusable on this
     host" (the `liveSkip` at `run.test.ts:168`). These are the
     W-125/W-130/W-132/W-134 live rows of the contained builder box. GitHub's
     ubuntu runners block unprivileged user namespaces (AppArmor,
     `kernel.apparmor_restrict_unprivileged_userns=1`), so CI never exercises
     the box; it is only checked when a receipt is minted locally.
   - Change: the CI workflow's `gates` job installs bubblewrap and sets
     `kernel.apparmor_restrict_unprivileged_userns=0` with sudo before
     `npm test`, so the live rows run in CI. The builder confirms the exact
     steps against the runner image.
