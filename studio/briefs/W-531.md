## Intent

The Patron: "standardize the naming conventions to {collegium}-{role}", "flexible enough for ... any project that bisellium will init". Today a sella id is free text and code reads several by literal (`"producer"`, `"ui-lead"`). After this round:

1. An officina that declares `sella_aliases: { since, live_until?, last_opus?, ids }` keeps the role contract: the table is valid in full or refused in full (`readSellaAliases`, the one reading `check` reports and `readManifest` throws), every collegium of a live row is lower-case words, and every live row is `{collegium}-{role}[-<qualifier>]`, the role one of seven (`lead`, `architect`, `builder`, `reviewer`, `clerk`, `runner`, `guest`; no eighth role, SPLIT 3), and `check` blocks a row outside it (`sella.name`) or a bad table (`manifest.aliases`). An officina without the table is unchanged: no real officina declares one in this round, so the mechanism lands inert.
2. An old id resolves to its canonical seat through `resolveSeat` (Seam S1), one hop, forever. History is never rewritten.
3. From the cutover a write records the canonical id. An old id at a live verb gets a notice until `live_until` (since + 90 days at the later round's cutover, 2027-02-18, SPLIT 5), and past it stays live while any pre-cutover opus is in flight, which `check` names before the expiry. An old id that ran on another model or harness than its canonical row never runs silently on that row: it is refused live, inside the window as well (the builder seat, below).
4. Every identity-bearing raw sella compare reads through the table (`compare-classification.md`: 34 sites converted, every other census line kept with its reason).
5. The officina's own seats decide: a `{collegium}-builder` row is builder-class, the write fallback is `hooks.default_sella`, the UI lead is whatever `ui-lead` reads as.

The settled splits, for the later round's roster: SPLIT 1 `qa-reviewer-spec` + `qa-reviewer-ui` (8/8); SPLIT 2 `ops-reviewer-security` (8/8, D-148); SPLIT 3 no eighth role (8/8); SPLIT 4 defer W-291, W-399 and W-513's slice, W-554's boot slice is behaviour 3, its route provenance goes to W-546 (8/8); SPLIT 5 a 90-day minimum, extended while a pre-cutover opus is open (7/8); SPLIT 6 today's design-lead keeps `design-lead` (8/8).

The builder seat (the Patron's ruling): `builder-codex` reads as `engineering-builder`, one seat; model and harness are routing data. The leads' concern is met by the refusal path: the table entry records the routing the old id ran on (`builder-codex: { to: engineering-builder, model: gpt-5.6-sol, harness: codex }`), and `aliasLiveUse` refuses a live use of an old id whose recorded routing differs from its canonical row's, naming both (`sella "builder-codex" is now "engineering-builder", which runs claude-sonnet-5 on claude-code, not gpt-5.6-sol on codex`). Reading the old id's records is unaffected. A Codex build is then dispatched as the canonical seat with its routing named by the dispatcher; no dispatch under the old id reaches another model's harness.

Threat model: mistakes, not adversaries (D-045).
