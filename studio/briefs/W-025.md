# W-025 — Officina screen

Collegium engineering · cascade 7

## Intent

Build the Officina screen and the shared navigation layer: a fasti strip
(signature element 4.2), four data panels between hairlines, a gate ladder
component (signature element 4.1), and a 44px nav bar with Inbox/Officina
links and a needs-you count badge. Depends on W-024's scaffold, tokens, API
client, and colophon.

The API is complete and frozen — no endpoint changes.

## Files owned

- `apps/web/src/screens/Officina.tsx` — the Officina screen.
- `apps/web/src/components/Nav.tsx` — 44px nav bar: Bisellium wordmark (text
  in Bricolage Grotesque 600, verdigris), Inbox link, Officina link, and a
  needs-you count badge (amber, from `/api/inbox` petitiones length).
- `apps/web/src/components/FastiStrip.tsx` — 14 day-columns, 28px tall. 3px
  verdigris ticks for cascade landings (from `/api/acta` filtered by kind),
  today as a 1px full-height ink rule, weekday initials in 11px small-caps
  beneath each column. Hollow 3px tick = officina open, no landing. No tick
  = closed day.
- `apps/web/src/components/GateLadder.tsx` — reusable: 6x6px marks at 3px
  gaps on a 1px rule rail. Filled ink = passed, hollow 1px outline = pending,
  `bad` fill with 1px diagonal = failed, `ok` fill = human-passed,
  half-height bar = waived. Width = function of gate count. Hover names the
  gate and its blocker. Used on both Inbox and Officina screens.
- `apps/web/src/components/BurnBar.tsx` — two right-aligned mono numerals
  (spent / allowance) and a 4px rule filled to `spent / allowance` fraction.
  Ink under allowance, amber past it.
- `apps/web/src/App.tsx` — **co-owned with W-024.** W-025 adds hash routing
  (`/#/inbox` → Inbox, `/#/officina` → Officina, default → Inbox) and wraps
  both routes in the `<Nav>` component. W-024's Inbox route stays; W-025
  adds the Officina route and the nav wrapper.
- `apps/web/src/api.ts` — **co-owned with W-024, append-only.** W-025
  appends:
  ```ts
  export function fetchOfficina(): Promise<OfficinaResponse>;
  export function fetchAerarium(period?: string): Promise<AerariumEntry[]>;
  export function fetchHealth(): Promise<HealthResponse>;
  export function fetchActa(days?: number): Promise<ActaEntry[]>;
  export function fetchOpera(filters?: { state?: string; collegium?: string }): Promise<OpusEntry[]>;
  ```
- `studio/ci/reds/W-025/*.log` — recorded reds.

The builder may add supporting files within `apps/web/src/` as needed; the
files above are the minimum.

## Interfaces

### API response types (from apps/server/src/store.ts)

```ts
interface OfficinaResponse {
  studio: string;
  patron: string;
  collegia: { id: string; name: string; magister: string;
              fallback?: string; autonomy: string }[];
  sellae: { id: string; name: string; collegium: string }[];
  probationes: { id: string; kind: string }[];
  wip_limit?: number;
}

interface AerariumEntry {
  collegium: string; period: string;
  allowance: { tokens: number };
  burn: { tokens: number };
  posture: string;
}

interface HealthResponse {
  at: string; ok: boolean;
  blocks: number; advisories: number;
  findingsByRule: Record<string, number>;
  autonomy: { paused: boolean; since?: string; reason?: string };
  lastTick: string;
  due: { kind: string; id: string }[];
}

interface ActaEntry {
  id: string; author: string; kind: string;
  title: string; at: string; evidence: unknown;
}

interface OpusEntry {
  id: string; title: string; kind: string;
  collegium: string; sella: string; state: string;
  tokens: number;
  probationes: Record<string, { status: string; evidence?: string }>;
  traditio: unknown;
}
```

### Nav component

```ts
interface NavProps {
  needsYouCount: number;  // petitiones.length from /api/inbox
}
```

44px tall, full width. Bisellium wordmark (text, not a logo glyph —
DIRECTION.md §2.10 rejects the anonymous house icon). Inbox and Officina
as two links. The needs-you count badge: amber text, visible only when > 0.
No breadcrumb bar, no second toolbar (DIRECTION.md §3: chrome budget).

### Gate ladder component

```ts
interface GateLadderProps {
  gates: { id: string; status: 'passed' | 'pending' | 'failed' | 'human_passed' | 'waived'; blocker?: string }[];
}
```

Width is `gateCount * 9 - 3` px (6px mark + 3px gap, minus trailing gap).
The 1px rail runs the full width. Hover on a mark shows a title with the
gate id and blocker (if any).

### Fasti strip

```ts
interface FastiStripProps {
  acta: ActaEntry[];   // from /api/acta?days=14
  today: Date;
}
```

14 day-columns from `today - 13 days` through `today`. Each column: a 3px
tick (verdigris filled if a cascade landed that day, hollow if the officina
was open but nothing landed, absent if closed). Weekday initial in 11px
small-caps beneath. Today column has a 1px full-height ink rule.

A "cascade landing" is an actum whose `kind` indicates a cascade completion.
The builder determines the exact `kind` value from the data; if unclear,
filter on `kind` containing "retro" or "cascade".

### Officina screen layout

Below the nav and fasti strip, four panels stacked between 1px `var(--rule)`
hairlines. Each panel has a section heading at 17/22 Bricolage 600:

1. **Decreta pending** — petitiones from `/api/inbox` (same data the Inbox
   screen uses). Shows count and subject lines.
2. **Posture and burn** — from `/api/aerarium`. Posture: the word itself at
   17px Bricolage 600 with its reason beneath at 13px. Burn: two mono
   numerals + 4px rule filled to spent fraction (BurnBar component).
3. **Lex status** — from `/api/health`. `blocks` count, `advisories` count,
   `findingsByRule` as a compact list of rule ids and their counts.
4. **Process health** — from `/api/health`. `ok` boolean, `autonomy` state,
   `due` items list, `lastTick` timestamp.

### Colophon

Reuses W-024's `<Colophon>` component on the Officina screen. The colophon
appears at the bottom of every screen's scroll (DIRECTION.md §4.5).

## Behaviours to test

1. Fasti strip renders exactly 14 day-columns spanning `today - 13` through
   `today`, with weekday initials in small-caps beneath each column.
2. The today column in the fasti strip carries a 1px ink rule at full
   (28px) height; no other column does.
3. A day with a cascade-landing actum shows a filled 3px verdigris tick; a
   day with no landing but the officina open shows a hollow 3px tick; a
   closed day shows no tick.
4. Gate ladder renders one 6x6px mark per gate on a 1px rail, with filled
   ink for `passed`, hollow outline for `pending`, `bad` fill with diagonal
   for `failed`, `ok` fill for `human_passed`, and half-height bar for
   `waived`.
5. Gate ladder hover on a mark shows the gate id (and blocker if present)
   in a title attribute.
6. BurnBar displays two mono numerals (spent / allowance) and a 4px rule
   filled to the spent fraction; the fill is ink when under allowance and
   amber when at or past allowance.
7. Posture panel shows the posture word at 17px Bricolage 600 with its
   reason beneath at 13px body text.
8. Nav renders the Bisellium wordmark, an Inbox link, and an Officina link
   within 44px height; a needs-you count > 0 shows an amber badge.
9. Hash routing: `/#/inbox` renders the Inbox screen and `/#/officina`
   renders the Officina screen; the default route (`/` or `/#/`) renders
   Inbox.
10. Colophon appears at scroll-bottom of the Officina screen, identical in
    format to the Inbox screen's colophon.

```bash
cd apps/web && npx vite build
npm run -s typecheck
npm run -s check -- studio --repo .
```

`bisellium serve --studio studio`. The nav switches between screens. The
fasti strip is visible on the Officina screen. The gate ladder renders on
at least one screen where opera with probationes are present.
