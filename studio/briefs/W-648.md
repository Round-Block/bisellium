## Intent

A builder's green rows for W-503 have to run in the opus's own worktree, `<repo>/.worktrees/W-503`. Today `bisellium run` cannot put a child there: a builder-class sella is refused `--no-worktree` (master run.ts:240-243, "a disposable confined clone is mandatory"), and any other run's child starts in the leased worktree or, with `--no-worktree`, in `--studio` (master run.ts:290). A builder may not `cd` or `env -C` into a worktree (the guard and clone-tests-meet-1114), so the rows wait.

After this opus, `bisellium run` takes `--cwd <dir>`, accepted only with `--opus <id>` and only when `<dir>` resolves (realpath) to `<repo>/.worktrees/<id>`, an existing directory. With it the run leases no worktree and builds no confined clone, the builder-class `--no-worktree` refusal lets the run through, and the child runs with that directory as its cwd. Every other use of `--cwd`, including with `--reclaim` or `--scratch`, is refused with exit 2 before any receipt, lease or child; with `--reclaim` the refusal comes before the reclaim touches a lease. Without `--cwd`, the verb is unchanged.

Threat model: mistakes, not adversaries (D-045). The flag keeps a builder's child out of every directory but its own opus's worktree; it is not a sandbox.

## Promises

Promise cwd: with `--opus <id>` and a `--cwd` that resolves (realpath, through a symlinked parent or a dot-dot segment) to `<repo>/.worktrees/<id>`, the child of a builder-class or any other sella runs with that real directory as its cwd and the receipt records it as `cwd`, no worktree is leased and no confined clone is built, and a builder-class run with `--no-worktree` is let through — limit: the child runs unconfined, with the inherited environment and the sella's git identity, not in the disposable confined clone a builder-class run gets without `--cwd` (`runBuilderCommand`, unchanged and not entered); the directory is not checked to be a git worktree or to be on `opus/<id>`; `--keep` and the release of a lease do not apply, since none is taken. Pinned by `W-648-b1` "a builder run with --cwd exits 0" and pinned by `W-648-b1` "a builder run with --cwd: the child's cwd is the opus worktree" and pinned by `W-648-b1` "the receipt records the worktree as cwd" and pinned by `W-648-b1` "a non-builder run with --cwd: the child's cwd is the opus worktree" and pinned by `W-648-b1` "a symlinked parent: the child's cwd is the real worktree".

Promise refusal: `--cwd` with `--reclaim` (with or without `--opus`) or with `--scratch`, `--cwd` without `--opus`, a `--cwd` that resolves to any directory but `<repo>/.worktrees/<id>` (another opus's worktree, the main checkout, a dot-dot escape, a directory inside the worktree, a symlink that escapes, a worktree that is itself a symlink to elsewhere), an id that is not one path segment, and a `--cwd` that does not exist or is not a directory, each exit 2 with the reason, before any receipt, lease or child, and with `--reclaim` before any lease is removed — limit: the directory is checked once, before the spawn; a swap of it between the check and the spawn is not seen (D-045). Pinned by `W-648-b5` "--cwd with --reclaim: the refusal names why" and pinned by `W-648-b5` "--cwd with --reclaim, no --opus: the refusal names why" and pinned by `W-648-b5` "--cwd with --scratch: the refusal names why" and pinned by `W-648-b2` "--cwd without --opus: the refusal names why" and pinned by `W-648-b3` "another opus's worktree: the refusal names why" and pinned by `W-648-b3` "the main checkout: the refusal names why" and pinned by `W-648-b3` "a symlink escaping the worktree: the refusal names why" and pinned by `W-648-b3` "a symlinked worktree: the refusal names why" and pinned by `W-648-b4` "a missing worktree: the refusal names why".

Promise unchanged: a run without `--cwd` parses, refuses, leases, spawns and records as on master, and the one visible change is the usage line, which reads `[--opus <id> [--cwd <dir>]]` in run.ts's and the banner's copy — limit: unpinned by a new row; the existing run rows (`run.test.ts`, whole), the shim rows that import run.ts and the banner row (`usage.test.ts`) pass on the prototype, and nothing else in run's behaviour changes.

Limits, stated:

- Reused, unchanged code these promises lean on: `takeValue`, `parseScratch` (W-474, which refuses `--cwd does not go with --scratch` in its own grammar), `reclaimWorktrees` (never reached with `--cwd`), `resolveRepoRoot`, `safeItemPath` (the shared id containment helper, writes.ts:106), `runBuilderCommand`, `writeReceiptStart`, `writeReceiptEnd`, `selectProvider` and the builder-class minter (`isBuilderClassSeat`, `seatInstance`). None is edited, and each keeps its behaviour.
- The check is by realpath and by path only. A worktree on the wrong branch, a stale worktree, or a plain directory created at `.worktrees/<id>` passes it.
- `bisellium red`'s own `--cwd` is unrestricted and unchanged; the two flags share a name only.

## Interfaces

**`opusWorktree(studioRoot, repoFlag, opus, cwdFlag)`** (run.ts, not exported): `{ dir: string } | { error: string }`. `dir` is the realpath of `cwdFlag` when it equals `<realpath of the repo>/.worktrees/<opus>` (the id checked by `safeItemPath`) and is a directory; otherwise `error` is the refusal's text after `bisellium run: `.

**`bisellium run --sella <sella> --opus <id> --cwd <dir> [--no-worktree] … -- <cmd…>`**: the child's cwd is `dir`; exit is the child's, or 2 on a refusal. `--opus` keeps its meaning (a builder instance's id; `opus/<id>` as the base of a lease, unused here).
