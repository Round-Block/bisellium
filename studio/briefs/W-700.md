## Intent

The meet found that a lesson does nothing: check only advises on one that names no fix, retro files stubs with no finding in them, a halted target counts as a fix in flight, six lesson prefixes have no owning lead, and the records-landing command cannot carry lessons at all, so 27 sat unlanded for days. After this opus:

1. The records-landing command carries `studio/lessons/` like opera, ci logs, decisions and acta (land.ts `STUDIO_DIRS`).
2. `addressed_by` is the lesson's disposition: an opus, a rule id or a decision as today, or `prose:<reason>` (it stays prose, and why) or `closed:<sha>` (the commit that fixed it). Both new forms are validated. A `closed:` commit closes the class; a `prose:` reason names the fix for `lesson.unfixed` but leaves the class open, so a prose disposition never quiets a recurring class (the meet's concern that prose becomes the default).
3. `lesson.unfixed` blocks for a lesson whose `at` is on or after `defaults.lesson_fix_required_from` (a `YYYY-MM-DD` day in bisellium.yml), and advises before it; older lessons are untouched (no backfill). The switch is on in `studio/bisellium.yml` at `2026-11-20`, pinned by a row on studio/. Absent or malformed, every lesson with no fix blocks and the message names the key, so a missing switch on studio/ fails loud.
4. Rule `records.unlanded`: a file git does not track under the officina's `lessons/`, `decisions/`, `acta/` or `ci/` is an advisory in check, and the CI command refuses to run any step while one exists. A brief and a spec-phase log ride their opus branch and are left out.
5. `retro --cascade` writes each finding's text into the lesson it files, not a stub, and refuses the whole draft, writing nothing, when a finding has no text (its `where` absent, not a string, or blank).
6. A halted opus, or one whose greenlight was declined (the "killed" of the meet: no opus state is named killed), is no fix in flight: the class is open with no fix named.
7. The production lex names an owning lead for the six unowned prefixes: eng-lead for mechanism, records and review; ops-lead for workflow, process and ci (the meet's eng and ops seats).

Threat model: mistakes, not adversaries (D-045).
