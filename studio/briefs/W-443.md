## Intent

A prototyped brief's genuine red command is not only prose: `next --perform --expect reds` replays the architect's series and runs each behaviour's written command, word for word (`redCommand`, W-326), and a builder copies it into a shell. The two reviews this class came from show how the written command and the evidence drift apart:

- **W-442 spec r2** (`ci/W-442-spec-2.log` #1, blocking): the written command ended `--grep W-442-b1\s`, unquoted. A shell consumes the backslash, so the copied command passes `W-442-b1s`, selects no test and cannot reproduce the red; the architect's `reds.sh` had run a quoted pattern, so its outputs did not validate the written command. The replay's own reader refuses that command (`the red command holds "\\" outside single quotes`), but only when the replay runs, at mint, after the spec is signed and reviewed.
- **W-360 spec r5** (#4, advisory): the browser rows cited as run had run only under `stub-run.sh`, not the command the brief names for the host.

**What "the command its evidence ran" means here, and why.** An output file cannot say what produced it unless it is told at the time. `bisellium red` already heads every recorded red with `# command: <argv, space-joined>`, and the producer's replay of prerequisite reds splits that header on whitespace to run it again (`prerequisiteCommands`, `lifecycle.ts`; W-462's brief reads it the same way). So the architect's red evidence carries the same header, written from the argv the shell actually passed (`run-red.sh`: `printf ' %s' "$@"` before running `"$@"`), and the check compares words, not text: the written command is read with the replay's own reader (`commandWords`: plain characters, or text in single quotes, nothing else a shell would read), and its words, space-joined, must be exactly the recorded line. Because that reader refuses every word holding whitespace, the space-joined form is lossless. Shell quoting is decided twice and the same way: the reader refuses any character a shell would interpret, and the header records what the shell produced.

**Which evidence.** The evidence a behaviour's genuine red cites: on that behaviour's item, from the line holding its `**Genuine red:**` marker to the item's end, every backticked span that is an evidence citation in W-445's sense (an absolute or `~/` path, or a name ending in `.out` or `.log`; directories aside), resolved exactly as a quoted claim's citation is, under the brief's evidence roots. At least one must record a command, and every one that records a command must record the written one, so a stage output run with another command is caught too, and an output that records none (an acceptance summary such as `red-accept.out`) is not compared. A citation that names no single readable file is refused, fail-closed, as W-445's are.

**Where, and for which briefs.** At the signer's spec verdict, beside W-306's ledger and W-445's citation check, in `packages/commands/src/verdict.ts`: the one admission point that reads evidence files (`evidenceText`), and the one the architect passes at every signed revision, so W-442's command would have been refused at round 1 instead of found at round 2. Only on a brief that names a prototype (`ruledCases(...).prototype`, W-381): that is the brief whose written command a replay runs and whose reds the architect ran; without a prototype the builder records the red with `bisellium red`, which writes the header from what it ran. Not in `readBriefAdmission` (text only, and the officina check runs it over every active opus, whose evidence may since have been cleaned away), and not in `next`'s replay, which keeps refusing an uncopyable command at mint as before. To read the command with the replay's own reader rather than a second one, `commandWords` and `redCommand` move unchanged from `packages/cli/src/prototype-replay.ts` into `packages/commands/src/brief-admission.ts`, beside `behaviourItems` which `redCommand` already reads; the CLI cannot be imported from `packages/commands`, and the replay imports them back.

**What it refuses on master today.** Every one of master's 48 prototyped briefs (of 228), because no evidence before this opus records its command (`census.out`); none of them has a command the reader refuses. The check runs only when a brief is signed, so no signed or finished brief is reopened; a brief signed after this merges heads its red outputs as `run-red.sh` does. W-442's round-2 brief is refused at its uncopyable command, and W-360's round-5 brief is refused only for its missing headers (`sources.out`): its stub outputs are cited outside the genuine reds, a stated limit.
