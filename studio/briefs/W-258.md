## Intent

D-080 G: the builder reads its own diff against the build-review prompt once before it hands off, itself, and fixes what it finds; it makes no Codex call and records nothing, and the Codex build review stays the single gate (D-066 C). D-069 folds ten lesson classes into the same read: every reachable path and regression fixture a fix affects, both bounds of each changed validation, a negative fixture or a removal for each changed assertion, and regression test titles true to a changed domain. The ops speed audit (2026-10-14, rank 4) counts 55% of build rounds failing at 39 minutes each.

Where the instruction lives: the first builder's brief is filled from `studio/prompts/builder-brief.md` (W-241, D-082 A) for every opus, so the instruction is one new paragraph there, between the Order paragraph and the Gates paragraph: after the last behaviour's commit and before the gates (so the gates and `ci --opus` run on the fixed tree), the builder reads its diff (`git diff origin/master...HEAD`) once, as the censor would, against `studio/prompts/build-review.md` and the brief; no Codex call, no other agent, nothing recorded; the four D-069 points; fixes land as further commits in Files owned, never an amend of a recorded red's commit; a finding needing a file outside Files owned, a brief change or an unnamed row is a stop-and-report. The prototype's paragraph is the text to ship.

What pins it: `process.prompt_templates` (W-241) already blocks `bisellium check` when a template lacks a required text. `BUILDER_SELF_REVIEW`, eight texts of the paragraph, joins `PROMPT_TEMPLATES["prompts/builder-brief.md"]`: `Self-review before handoff`, `studio/prompts/build-review.md`, `No Codex call`, `nothing is recorded`, `every reachable path and regression fixture`, `the accepted and the rejected bound`, `a negative fixture or a removal`, `test titles true to a changed domain`. No new rule id, verb, record field or hook: the smallest change that holds. `.claude/agents/builder.md` is not touched (code-owned, and W-310's lane); the template is what every first builder reads.

Promise template-carries-self-review: in an officina whose manifest declares the `ops` collegium, `bisellium check` blocks at `prompts/builder-brief.md` unless the template holds each of the eight self-review texts as a literal, case-sensitive substring, and its finding names each missing text — limit: presence is checked and wording is not; a text found anywhere in the file (the usage note included) passes; the rule's reading of the path is `readContainedRegularFile`'s, reused unchanged (D-076 E); an officina without the `ops` collegium is not checked (W-241's scope, unchanged).

Promise no-record: the self-review adds no verb, record field, log or Codex call; the build review prompt, `next`'s review perform and the review gate are unchanged — limit: whether a builder performs the read is not mechanically observable (nothing is recorded, by D-080 G); the check pins that the instruction is present in the template, not that it is followed.
