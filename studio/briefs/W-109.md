# W-109 — Public source-tool usability canary

## Intent

Answer one question cheaply: can the installed Codex client and
`gpt-5.6-luna` low complete one public synthetic task through W-108's existing
typed `orient`, `locate`, and `read` MCP server?

W-107 remains NO adoption and W-108 remains FAIL/REFUSED. This separately
signed, single-attempt scope does not reopen either result. It removes the
unavailable pre-spawn effective-tool-inventory proof explicitly; observed
permitted calls do not establish tool isolation or read-efficiency success.

Architect revision 2 resolves the security memo before implementation.

## Interfaces

One standard-library runner and its focused tests; no new framework, adapter,
verifier copy, model abstraction or dependencies. Import W-108's
`captureFixtureIdentity`, `exactCanaryArgv`, and `verifyCanary`; launch its
existing `mcp-server` mode. Its `runLiveCanary` seam is not a runnable path.
Use one public fixture already owned by W-108.

### Fixed execution and authentication

Resolve and freeze actual Codex and Node executable paths/identities and the
exact argv from `exactCanaryArgv`, prompt, runner/test, W-108 adapter, production
source, registry/fixture identities and limits. The prompt requests
`orient -> locate -> read` and reveals neither expected fact
`cobalt-orchid-731` nor citation `source.md:3`. Use `--json --ephemeral`,
`--ignore-user-config --ignore-rules --strict-config`, read-only sandbox,
empty fresh cwd, Luna and low effort exactly as supplied by that helper.

Create a mode-0700 private runtime with `mkdtemp` beneath one designated
owner-owned temporary parent, outside repository and retained evidence.
Stage only the current user's `~/.codex/auth.json`: open no-follow, verify a
regular file owned by the user with mode 0600, and copy via an exclusive
mode-0600 destination into the temporary CODEX_HOME. Do not copy config,
skills or other home contents. Missing/unsafe auth refuses before the marker.
Never print, hash, publish or retain credentials in public evidence. Reading
credentials in memory solely for copying and leak checks is permitted.

Construct the child environment from scratch: only CODEX_HOME, HOME, PATH,
LANG and LC_ALL, with both homes pointing to the temporary runtime and a
fixed minimal executable PATH. Record these nonsecret values in the freeze;
inherit no API key, proxy, Node injection, provider or shell variables.
The existing server env={} is not evidence that inherited values are absent.

### One attempt and bounded process lifetime

Validate freeze/config identities, empty cwd, authentication staging and
absence of any marker/result; recheck frozen hashes immediately before
exclusive atomic marker creation. The marker binds freeze hash and private
runtime path. Then spawn exactly once; any failure after marker creation
consumes the attempt, including spawn/client failure. No resume or retry.

Launch a detached POSIX process group without a shell. Close stdin after the
frozen prompt. Parent enforces 120 seconds for the whole attempt; reuse the
server's 10-second initialization timer. Do not claim a separate 10-second
synchronous-call deadline. The parent deadline must terminate a hung server.
Capture caps: stderr 64 KiB, model stdout 256 JSONL records/1 MiB, server
transcript 1 MiB; existing server limits are four call attempts and 32,768
cumulative result bytes. Count raw bytes before decoding/normalization.

On any cap, timeout or failure, stop retaining excess bytes and continue
draining/discarding pipes; signal the whole group with TERM, allow at most
one second, then KILL remaining members even if the direct child has exited.
Wait/reap the direct child, close/drain handles, and verify no live group
members remain before completion. Apply descendant cleanup also on normal
exit. A bounded cleanup failure is FAIL, never a hanging success. One fake
child test must include a grandchild holding a pipe; another must flood output.

### Private validation and publication

All stdout, stderr and server transcript bytes first remain in the private
runtime or bounded memory. Validate fatal UTF-8 decoding and complete JSONL
framing: no blank records, non-JSON records, incomplete terminal record or
bytes after the terminal event. Require newline-terminated records. Do not
filter, normalize, synthesize missing fields or discard unknown events to
make `verifyCanary` pass. It is the semantic inner check; the runner owns raw
framing, caps, freeze/command/environment identity and marker enforcement.

Before publication scan all proposed evidence bytes for the auth-file bytes
and nonempty credential values extracted locally from auth JSON (never log
those values). Any match suppresses raw publication and yields a fixed
nonsecret failure code. Do not publish arbitrary exception text. Unknown or
malformed event/stderr content is withheld; preserve only its byte count/hash
and fixed failure reason. Publish raw events/transcript only when framing,
credential scan and allowed event semantics pass; publish no freeform stderr.
Record stderr byte count/hash and a fixed diagnostic code instead. This
explicit withholding is not complete transcript evidence and cannot PASS.

Atomically publish public result/evidence only after validation, bound to the
freeze, with complete validated model/server JSONL when admissible, final
answer, usage, hashes, command and nonsecret environment, and marker. A FAIL
may retain only safe metadata when raw output is inadmissible. Write one
terminal result; never overwrite an existing result. Clean the private runtime
in finally on ordinary failures and handled termination signals.

SIGKILL/crashes can leave private data: retain the attempt marker permanently.
A cleanup-only mode may remove that marker's runtime after verifying its
resolved location stays beneath the designated parent, is no-follow,
owner-owned mode-0700 and belongs to this attempt. It must never spawn a model
or erase/reuse the marker. Document that this mode is needed after a hard crash.

1. Freeze, auth and one-attempt gate: drift, nonempty cwd, unsafe/missing auth,
   existing marker/result or repeat invocation refuses with zero spawns;

   failure consumes the attempt. Cleanup-only cannot clear the attempt.
2. Actual process controller with fake executables: stdin closure, bounded
   raw capture, parent timeout of a synchronous hang, grandchild/pipe cleanup,
   output flood, failure cleanup and one terminal result. Verify credential
   staging permissions/removal and leak-triggered publication withholding.
3. Actual raw-to-result path: synthetic PASS requires exactly three successful
   typed calls in order, matching complete events/transcript, fact/citation,
   usage, exit zero and caps. Reject malformed UTF-8/framing, blank/trailing
   records, unknown/fallback/foreign tools, command/file/web activity,
   missing/extra/retried calls, argument/result/hash drift, wrong answer and
   missing usage. Exercise the production runner path, not only injected seams.

Each behaviour needs its own assertion-level recorded red before implementation.
Deterministic tests never invoke a vendor model. The live attempt is acceptance
evidence, never a red. Reuse W-108 semantic verifier fixtures where practical;
do not duplicate its complete test suite.

## Acceptance

Focused tests, full tests, typecheck and lint pass before the single public
model attempt. PASS means only this client/model/version used the adapter on
this fixture with the three successful calls, correct fact/citation, exact
transcript match, usage and held limits. It does not prove effective isolation.

Any refusal, spawn/client failure, unsupported event, forbidden observed
action, wrong answer, timeout, cleanup failure, cap breach or mismatch is FAIL
for this harness/version. Preserve precise failure category; usability remains
unproven when the model never successfully uses the adapter.

After PASS or FAIL stop. No prompt/config tuning, repair, retry, resume,
private/multi-project run or savings trial. Further work requires a fresh
signed scope. If the thin wrapper cannot satisfy these boundaries using the
existing exports, stop before model spawn and report the concrete limitation;
do not expand this opus into a general harness.
