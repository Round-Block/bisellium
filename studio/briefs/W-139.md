# W-139 — record-only CI must run the tests that read the real officina

Draft, backlog only (orchestrator, 2026-10-04). Not specified; no build is
authorised. Found while closing cascade 43.

## Intent

W-131 gave record-only PRs a ~15 s `gates` path that skips `npm test`. But
some tests read the real `studio/` (for example `check.test.ts` W-076
behaviour 5 pins the real officina's petitio findings). The retro PR #218
(studio-only: lessons and petitiones) therefore merged on the fast path and
turned master red; #219 fixed the test. A studio-only diff is not
test-irrelevant while any test reads the real officina.

Scope, to be set at spec time — one of:

1. The record-only path runs the subset of tests that read the real
   officina (a declared, checked list), or
2. Tests stop pinning live officina state (fixtures only), with a check rule
   that refuses a test reading `studio/` directly.
