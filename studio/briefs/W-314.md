## Intent

Today the build-review perform (`next <id> --perform --expect review`, and the chain's review rung) fills the round-1 prompt from `prompts/build-review.md` in the opus worktree's studio (`packages/cli/src/next.ts:1659`, `readContainedRegularFile(wt.studio, …)`), and a later round's prompt comes from `prompts/later-round.md` in the same studio (`scripts/review-packet.mjs:256`, given `studio: wt.studio` at `next.ts:1650`). So an opus that edits either template edits its own reviewer's prompt, before the Patron's merge can catch it: W-312 rewrote `build-review.md` line 10 and its round 1 was judged against a sentence that was not yet true for it.

After this opus both templates are read from the main checkout's studio (`f.studioAbs`, the `--studio` that `next` opened from the repository's main checkout, which `runNext` requires), never the opus branch. A prompt edit still lands atomically with its code, and governs from the next opus.

A later round's packet `delta.diff` today is the source diff since the commit that added the previous round's log, excluding the officina (`review-packet.mjs:225`). A studio-only fix (gate logs, a brief edit, a red, the record) shows as an empty delta, as at W-312 round 2. After this opus `delta.diff` is that source diff followed by the officina's diff over the same range, so the reviewer, whose unchanged prompt says "judge only the change since that round: `<PACKET>/delta.diff`", is shown every change since its last round.

Cause fix: this is the D-076 D cause fix for `review×evidence-backfilled-or-absent`.

Threat model: mistakes, not adversaries (D-045). The main checkout is the orchestrator's; its working copy is read as it stands.

Bootstrap: this opus is reviewed under master's ladder, which reads `prompts/build-review.md` and `prompts/later-round.md` from this opus's branch. This opus changes no file under `studio/prompts/`, so both are master's text byte for byte, and the review packet stays true for it: round 1 reads master's `build-review.md`, whose line 10 (W-312's gate-log sentence) holds once the builder's `bisellium ci --opus W-314` has passed and its gate logs are committed, which master's ladder requires before it orders review (`admitCurrentGates`). A later round of this opus is built by master's `buildPacket`, so its `delta.diff` is the source diff only, the packet every opus before it had: master's `later-round.md` ("judge only the change since that round: `<PACKET>/delta.diff`") over-reads that delta for a studio-only fix of this opus's own, which the reviewer then reads in the checkout or not at all (the gap this opus closes, from the next opus; a stated limit for this opus's own later rounds).
