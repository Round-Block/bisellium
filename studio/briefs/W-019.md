# W-019 — Repo hygiene the model preaches

Builder D · collegium engineering · cascade 4b

## Intent

`studio/bisellium.yml` declares a `lint` probatio whose command is `true`. Every
opus in this repo carries a green lint certificate that certifies nothing.
Meanwhile the docs registry has been "planned, not yet built" since the adoption
contract was written, there is no CI, and a clone has no way to learn how work
enters. Make "clean code is a gate" true here before the model claims it
elsewhere: a real linter, a real CI run, a docs registry with a rule behind it,
and the three files a contributor actually needs.

You are the only builder allowed to edit the root `package.json` — and only for
the four things named below.

- `package.json` (root) — **only** `devDependencies`, the `lint` and
  `format:check` scripts, and `engines`. You do **not** add other builders'

- `.github/workflows/ci.yml`

- Front matter on `docs/*.md`, `README.md`, and `GLOSSARY.md` if it exists

## Interfaces

```ts
// packages/cli/src/rules/docs.ts
import type { Finding } from "../check.js";
import type { RuleOpts } from "../check.js";   // { now: Date; repo?: string; manifest?: unknown }
export function checkDocs(root: string, opts: RuleOpts): Finding[];

// packages/cli/src/docs.ts — self-parsing
export interface DocEntry { path: string; kind: string; owner: string; tier: string; review: string; kill: string }
export interface DocRegistry { at: string; docs: DocEntry[] }
export function buildRegistry(repoRoot: string, now: Date): DocRegistry;
export function runDocs(args: string[], opts?: { now?: Date }): { exitCode: number };
//   bisellium docs registry [--repo <dir>] [--now <iso>]
```

`checkDocs` is called from inside `checkStudio`, where `root` is the
**officina** — but `README.md`, `GLOSSARY.md` and `docs/` live at the **repo
root**. `studio/` has no `docs/` directory, so a rule that reads `root` is dead
on arrival under the only invocation anyone runs. Read `opts.repo`; return `[]`
when it is absent. `owner` must be a declared sella or the patron, which is why
`opts.manifest` is in the signature.

// scripts/changelog.mjs

## The work

**Lint.** Add `eslint` + `typescript-eslint` (flat config) and `prettier` as
devDependencies. Choose a rule set **that passes the tree as it stands**:
`no-unused-vars` (`argsIgnorePattern: "^_"`), `no-undef` off (TS handles it),
`no-console` off (this is a CLI), plus `@typescript-eslint/no-floating-promises`
and `no-explicit-any` only if already clean. Record the red with a deliberately
broader set, then narrow. Anything that still needs fixing is fixed by a
committed script (`scripts/lint-fix.mjs`), never by hand. `eslint .` may cover
`packages/`, `apps/` and `adapters/` precisely because the config is chosen not
to demand edits in another builder's files.

**Format — deliberately scoped.** `prettier --check` over this tree warns on
`studio/opera/*.md`, `docs/ADOPTION.md`, both `bisellium.yml` files and
`packages/cli/src/check.ts` (verify this and record it as your red). Making it
green would mean rewriting files owned by A and C, reformatting officina
bookkeeping the standing rules say is never hand-edited, and collapsing the
column-aligned inline mappings in `examples/sample-studio/bisellium.yml` that
`packages/cli/src/tick.test.ts:156` and `:284` do exact-string surgery on.

So: `"format:check": "prettier --check ."` with a `.prettierignore` that
excludes `studio/`, `examples/`, `docs/`, `*.md`, `package-lock.json`,
`.bisellium/`, `node_modules/`, **and** — with a one-line comment naming this
cascade — `packages/`, `apps/`, `adapters/`. What remains is the config and
`scripts/` you own. Also write `scripts/format-all.mjs` (the mechanical pass)
and record in `CONTRIBUTING.md` that widening `.prettierignore` is the first
task of the next cascade, once the moved files settle. A gate that is honest
about its scope beats one that is green because someone rewrote a colleague's
diff.

**CI.** `.github/workflows/ci.yml`, on `push` and `pull_request`: node 25,
`npm ci`, then `typecheck`, `lint`, `format:check`, `test`, and `check --repo .`
on **both** officinae. Read-only — CI never runs `verify` (it would write
certificates from a machine that is not the officina). Add the badge to
`README.md`. **`npm ci` cannot succeed in your worktree**: W-016 adds the
`packages/commands` workspace and drops `apps/server`'s `@bisellium/cli`
dependency, so the lock only matches the tree after all four land. Commit the
lock your own `npm install` produces, mark it provisional in your report, and
leave CI validation to the integrator (behaviour 11 checks the file's content,
not a run).

**Contributor files.** `CONTRIBUTING.md`: how work enters (`new --brief` → spec
→ `building`), how a cascade is launched, the standing rules, the
`Co-Authored-By` trailer, the prettier scope note. `CHANGELOG.md`: generated by
`scripts/changelog.mjs` from `git log`, grouped by commits whose subject starts
`Cascade N`, with everything after the newest cascade under "Unreleased".
`.editorconfig`; `.nvmrc` pinning node 25; `"engines": { "node": ">=25" }`.

**Docs registry.** Front matter on every `docs/*.md`, `README.md` and
`GLOSSARY.md`:

```yaml
---
kind: contract | model | template | guide | index
owner: <sella id, or patron>
tier: ROM | reference | archive
review: 2026-12-01       # ISO date this doc is next due a read
kill: <the condition under which this doc should be deleted>
---
```

Both rules **advise** — documentation drift never blocks a build.
`doc.fields`: unregistered `kind`; `owner` not a declared sella or the patron
(from `opts.manifest`); a missing key; a `review` date before `opts.now`.
`doc.link`: a dead relative link from a `docs/*.md` file.

W-018 adds body text to `docs/ADOPTION.md` and `docs/LEX_TEMPLATE.md` in the
same window; you add only their front matter, so the two edits touch disjoint
byte ranges. Say so in your report.

**LICENSE.** Do **not** choose one. Create `studio/petitiones/P-001.md`
(`from: producer`, `to: patron`, `state: needs_you`) titled "Choose a license",
listing MIT / Apache-2.0 / proprietary with one line each. The choice is a
judgment; judgments go to the Patron.

## Behaviours to test

1. `npm run -s lint` exits 0 on the repo as you leave it (red: the pre-narrowing
   run's failing output).
2. `npm run -s format:check` exits 0 with your `.prettierignore` (red: the same
   command with the four paths above un-ignored).
3. `scripts/lint-fix.mjs` is idempotent — a second run changes no file.
4. `groupByCascade` splits a fixture `git log` into one group per `Cascade N`
   subject, reverse-chronological, with later non-cascade commits under
   "Unreleased".
5. `scripts/changelog.mjs` is deterministic on a fixture log and writes nothing
   outside `CHANGELOG.md`.
6. `doc.fields` advises for: unknown `kind`; `owner` not a declared sella or the
   patron; each missing key in turn; a `review` date before `opts.now`. Each
   clears when fixed.
7. `checkDocs(officinaRoot, { now, repo: repoRoot, manifest })` produces **no**
   findings for the repo as you leave it at `now = 2026-09-18T20:00:00Z`, and
   returns `[]` when `opts.repo` is omitted — assert both.
8. `doc.link` advises for a relative link in `docs/` pointing at a missing path,
   and ignores `http(s)` links and bare anchors.
9. `bisellium docs registry` writes `.bisellium/registry.json` with one entry
   per registered doc and an `at` matching `--now`; two runs at the same `--now`
   are byte-identical.
10. `checkDocs` returns `[]` for a repo root with no `docs/` and never throws.
11. `.github/workflows/ci.yml` parses as YAML; its steps include `typecheck`,
    `lint`, `format:check`, `test`, and two `check` invocations naming `studio`
    and `examples/sample-studio` with `--repo .`; the string `verify` appears
    nowhere in the file.

Record the red for each before implementing.
