## Intent

W-547's spec review failed twice on one class: a lock input (a step marker, a run receipt, `queue.yml`, an opus record) whose read or shape error was read as absent, patched site by site. This opus puts one read under all of them: `readInput` in `@bisellium/schema` returns absent, valid or error, absent only for file-not-found, and the loaders for those four inputs are built on it, with their closed sets read where they are defined. The W-547 readers and `next.ts`'s lock-path reads call the loaders, so W-559's four open paths become errors `land` and `retro --daily` refuse on and `next` holds its meanwhile line on. A census lists every raw read of those inputs left outside the loaders, as a warning.

1. **One shared read (behaviour 1).** `readInput(label, read, shape)` in `packages/schema/src/read.ts`, exported by `@bisellium/schema`; the loaders `loadOpusRecord`, `loadMarker`, `loadMarkers`, `loadReceipt` in `packages/cli/src/inputs.ts`; `readQueue` reads `queue.yml` through `readInput`.
2. **Markers fail closed on their step and keep a `.json` output an output (behaviour 2; W-559 1 and 2).**
3. **A queued state outside the lifecycle is an error (behaviour 3; W-559 3).**
4. **A held derivation input error of the next entry is an error (behaviour 4; W-559 4).**
5. **The census warns (behaviour 5).**

### Input domain

**The rule, once for every lock input: absent is file-not-found only.** Each input below has one valid domain, one valid absence (`ENOENT` from its reader) and one loader. Every other read failure and every value outside the domain is an error the loader returns and its caller propagates, and a rejection fails closed: `readLocks` and `mainWriter` return it, `land` and `retro --daily` refuse, `next` holds the spec review and names no meanwhile step. Nothing is skipped and counted as absent.

**The rule covers every directory a reader descends or lists, not only the file it opens (revision 2, the class).** Under each loader root (the main checkout's `.bisellium`, the studio, and each `.worktrees/<id>/studio`), every component a reader passes and every collection it lists with `readdirSync` (`.bisellium`, `.bisellium/steps`, the studio, `opera/`, `receipts/`, each `receipts/<sella>/`, `.worktrees`, `.worktrees/<id>`) is a real directory reached with no symlink, walked component by component (`walkReal`) before it is listed; and a file a reader stats before its loader reads it is `lstat`ed, never followed through a symlink. Only `ENOENT` at the first missing component is absence; a symlink (to a real copy, to an empty directory, or dangling), a non-directory, or an unstatable component is an error. The main checkout itself is the trusted root and is not walked.
