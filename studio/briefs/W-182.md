## Intent

Decree family: isolated-smoke-port

`apps/web/playwright.config.ts` (W-029) runs Vite on fixed port 5199. Its `webServer.url` and `use.baseURL` point there, and outside CI `reuseExistingServer` is true. When two runs share one machine, the second either fails because 5199 is taken, or quietly tests against the first run's server. Lanes in separate worktrees (W-169) share the machine's ports. They do not share a checkout.

W-182 gives each run its own listener and keeps every existing mechanism. The webServer command adds `--host 127.0.0.1 --port 0 --strictPort`, so the OS chooses a free port and Vite prints it in its `Local:` banner. Playwright 1.63.0's `webServer.wait.stdout` strips VT control codes, matches the banner, copies the named group `smoke_port` into `process.env.SMOKE_PORT` (upper-cased), and only then loads the test files. Workers inherit that environment through `fork`. The spec file overrides `baseURL` with a fixture function, so the port is read when each test's fixtures are set up, not when the file loads. Nothing probes for a port and releases it before Vite binds.

Promise own-port: every `test:e2e` run that starts gets the port its own Vite process bound, and its browser `baseURL` is that port, so two simultaneous runs never contend for one port or reuse each other's server — limit: this covers the smoke suite's Vite listener only. Two runs still share Vite's dev proxy target for `/api`, `127.0.0.1:4477` (`apps/web/vite.config.ts`). The `?demo=1` rows do not depend on it, but rows that load `/` request `/api/inbox` (refused when no server listens, as on master). Two runs in the same checkout also share `apps/web/test-results/`.

Promise capture-closed: no smoke test runs until Playwright has captured a port from its own Vite's banner, and a captured or inherited value that is not a decimal port from 1 through 65535 fails each test before its browser context is created — limit: `smokeBaseURL` checks the value's form and range, not where it came from. If an inherited `SMOKE_PORT` were set and the banner never matched, `_waitForProcess`'s 30 s deadline fails the run before any test loads.

Promise rows-kept: W-029's five rows keep their titles and bodies byte for byte, and two rows are added — limit: `test:e2e` stays outside root `npm test` and outside CI. The `web-e2e` job runs the separate served suite (`test:serve`), so nothing automatic runs these seven rows.

No row, step or gate is removed or weakened (production lex §11). The threat model is mistakes, not adversaries (D-045).

## Interfaces

```ts
// playwright.config.ts
const VITE_READY = /Local:\s+http:\/\/127\.0\.0\.1:(?<smoke_port>\d+)\//;

// smoke.spec.ts
export function smokeBaseURL(port: string | undefined): string; // `http://127.0.0.1:${port}`
test.use({ baseURL: async ({}, use) => { await use(smokeBaseURL(process.env["SMOKE_PORT"])); } });
```

`smokeBaseURL` accepts only `^[1-9][0-9]{0,4}$` with a value of at most 65535. Anything else throws an `Error` that names the value. `apps/web/tests/` is not in `apps/web/tsconfig.json`'s `include` (`src` only), and `eslint.config.mjs` does not enable `no-empty-pattern`, so the `({}, use)` pattern Playwright requires needs no suppression.

## Behaviours to test

1. **The smoke browser uses the port its own Vite printed.** The row is `W-182 behaviour 1: the smoke browser uses the free port printed by its own Vite process`. It expects `process.env["SMOKE_PORT"]` to match `^[1-9][0-9]*$` and the `baseURL` fixture to equal `http://127.0.0.1:<that>`. It then goes to `/` and expects `new URL(page.url()).port` to equal it. After the red, the config change, `VITE_READY`, `smokeBaseURL` (interpolation only) and the `test.use` land.

   **Genuine red:** on master, with 5199 free, nothing sets `SMOKE_PORT`, so the first `expect` gets `undefined` and fails. Record it, from the repo root, with `bisellium red W-182 --behaviour 1 --studio studio --cwd apps/web -- npx playwright test --grep W-182.behaviour.1` (no argument contains whitespace). No existing row or fixture flips. W-029's five rows pass before and after.

2. **A missing or malformed port is refused.** The row is `W-182 behaviour 2: a missing or malformed captured smoke port is refused`. It expects `smokeBaseURL("1")` and `smokeBaseURL("65535")` to return their loopback origins. It expects `undefined`, `""`, `"0"`, `"01"`, `"65536"`, `"-1"`, `"1.5"`, `" 5199"` and `"5199 "` each to throw. Then the check lands in `smokeBaseURL`.

   **Genuine red:** after behaviour 1, `smokeBaseURL(undefined)` returns `http://127.0.0.1:undefined`, so the first `toThrow` fails (`--grep W-182.behaviour.2`). Behaviour 1 and W-029's rows stay green.

Existing assertions that do not flip: W-029's five rows; `scripts/ci-workflow.test.mjs` line 309 (`test:e2e === "playwright test"`); `W-110 behaviour 8` in `apps/web/test/served-config.test.ts` (it reads the serve config only); every `tests-serve` spec, and `scripts/served-e2e.mjs`.

## Defaults for the Patron to veto

1. **Use what is installed.** Vite takes port 0, and Playwright captures the port Vite prints. No dependency and no wrapper process are added.
2. **Bind to `127.0.0.1`**, so the banner, the captured URL and the browser all use the same host.
3. **Never reuse a running server.** Each run starts and stops its own Vite.
4. **Read the port at fixture time, not at file load**, so `playwright test --list` and editors that only list tests keep working.
5. **Leave CI placement alone.** The smoke suite stays a local suite.
