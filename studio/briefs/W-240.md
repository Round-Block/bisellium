# W-240 — receipt mints fail offline since W-236: `bisellium ci --offline`, passed only by the host recomputation

Status: **signed spec, revision 1** · drafted by Codex (`~/.bisellium-evidence/W-240-draft/W-240-draft.md`), checked against the code on a scratch copy, cut and signed by the architect (`claude-opus-5-5`) under D-027 · 2026-10-13 · master 0e37e56b. Notes: `~/.bisellium-evidence/W-240-spec/census.txt`.

Read enumeration: none: the change adds no reader; `ci` gains one boolean flag and the runner one argv entry.

## Intent

Decree family: receipt-mint-offline-audit

W-236 made `npm run -s audit` the first `CI_STEPS` entry. The receipt host recomputes `bisellium ci --opus …` in a `bwrap --unshare-all` cell with no network, so every mint stops at `bisellium ci: step failed (exit 1): npm run -s audit` (`~/.bisellium-evidence/W-221-review/r6/receipt-mint.log`). The Patron's ruling (2026-10-13): `bisellium ci --offline` skips that one step, and only `scripts/run-builder-host.mjs`'s producer recomputation passes it. Threat model: mistakes, not adversaries (D-045).

## Files owned

- `packages/commands/src/ci.ts`: `--offline` joins `runCi`'s boolean flags and `USAGE`; with it the step loop runs `CI_STEPS` without `"npm run -s audit"`.
- `packages/commands/src/usage.ts`: the `ci` line gains `[--offline]`.
- `docs/ADOPTION.md` "Running ci": the usage line gains `[--offline]`, and one sentence says it skips the audit step and that the receipt host passes it.
- `scripts/run-builder-host.mjs`: the producer gate's `cmd` gains `"--offline"` after `"ci"`.
- `packages/cli/src/ci.test.ts`: row 11, behaviour 1 below.
- `scripts/host-cells.test.mjs`: one node:test, behaviour 2 below, outside every `runs(n)` gate and run only when no `--behaviour` is given (`only === undefined`).

## Interfaces

`bisellium ci [--ref <ref>] [--opus <id>] [--studio <dir>] [--repo <dir>] [--allow-dirty] [--offline]`

With `--offline`, `runCi` runs the six other `CI_STEPS` in their order; the `--ref` install (`npm ci --no-audit`) and `--opus`'s `verify` are unchanged. `packages/cli/src/main.ts` dispatches `ci` before its own flag allowlist, so it is unchanged. The producer argv becomes `… main.ts ci --offline --opus <id> --studio /candidate/<studio> --repo /candidate`.

### Input domain

A rejection fails closed: no step runs after it and no certificate is written.

| Record | Valid domain | Rejected by |
|---|---|---|
| `ci` argv | The existing flags plus a bare `--offline` | `parseFlags`: an unknown flag (`--offline=x` included) or a valued flag with no value is an error; `runCi` prints it with `USAGE` and returns exit 2 |
| Each run step's exit | 0 | `runCi`: the first non-zero `runStep` result stops the loop and returns exit 1 |
