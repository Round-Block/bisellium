## Intent

The sandbox mounts an empty placeholder at `.git/objects/info/alternates` in the agent clone, beside a `.claude-sandbox-noreplace` folder (created 2026-11-03 16:35 SGT; `real-inputs.out` shows its `-rw-r--r-- 0` and the `ro` bind mount; `rm` in a session gives EBUSY, as filed). W-369's `sync_inputs` refuses any entry at that path, so every sync refuses, and the Patron moves master by hand after each merge touching `packages/`, `apps/` or `scripts/`.

After this opus `sync_inputs` accepts exactly a regular file of zero bytes at that one path. An empty alternates file names no object store: `git count-objects -v` lists no `alternate:` line for it, and row b1 keeps that assertion live with a file that does name one. On the real clone as this session sees it, master's `sync_inputs` stops at this path and the prototype's accepts every input (`real-inputs.out`, exit 0), so no second input fault waits behind this one.

**Decided: the other three paths stay refused.** `info/attributes`, `info/grafts` and `objects/info/http-alternates` are refused as now, even when empty. Only the observed placeholder is admitted; none of the three is there on the real clone (`real-inputs.out`). If the sandbox ever places another, the sync refuses and names it, and that is a new opus.

**Decided: the refusal's words stay.** A refused entry at any of the four paths still prints `<path> exists`, so W-369-b1's row for an alternates file with content passes unchanged.

**Decided: the check is one `stat`, never followed.** `stat -c '%A %s'` without `-L` makes one lstat, which returns the type and the size from the same call. Bash's `-f` and `-s` follow a symlink and take two calls, so they would accept a link to an empty file. `%A`'s first character is not translated, where `%F`'s words are.

**Decided: the race stands, and is a limit.** Git has no switch that stops it reading `objects/info/alternates`, so no check in the script can close the gap between the judgement and git's read; re-checking before each git call narrows it without closing it. Master has the same gap for a file planted just after its check, so this opus adds no new window. It does add one more way into that window: the file is now there to be written rather than created. Inside the sandbox it is mounted read-only (`real-inputs.out`), which is the sandbox's, not promised here. Git names objects by their hash, so a store named after the judgement can add objects and cannot change what a commit holds. The threat model stays W-369's: mistakes, not adversaries (D-045).

**Checked: `scripts/run-builder-host.mjs:503` is untouched.** Its `existsSync` reads `objects/info/alternates` in the clone it has just made with `--no-local --no-hardlinks --dissociate` under its runtime folder (lines 487 to 503), to prove that clone owns its objects. That is a fresh clone, not the agent clone. The same clone step run here leaves no alternates file (`host-clone.out`).

Promise placeholder: when the entry at `<agent clone>/.git/objects/info/alternates` is a regular file of zero bytes by one `/usr/bin/stat -c '%A %s'` that does not follow a symlink, `sync_inputs` goes on to its next check, and the sync then behaves as it does with no entry there — limit: the entry is judged once, before the sync's git calls, so a write after the judgement is read by those calls (W-369's Promise sync-inputs limit, unchanged); the mode, the owner and the hard links of the file are not judged; `stat`, git's reading of an empty alternates file and the sandbox's mount are reused and not promised (D-076 E). Pinned by `W-505-b1` "the empty placeholder syncs" and pinned by `W-505-b1` "git names no store for the empty file".

Promise refusal: any other entry at that path (content of one byte or more, a symlink wherever it leads, a directory, a FIFO), and any entry at `info/attributes`, `info/grafts` or `objects/info/http-alternates`, refuses with `sync: refused: <path> exists; master was not moved`, exit 1, before any git runs in the agent clone — limit: a socket or a device takes the same rule, by `%A`'s first character, and no row makes one; a `stat` missing or failing refuses with the same words, which then do not name the real cause. Pinned by `W-505-b1` "a symlink to an empty file at alternates: refused" and pinned by `W-505-b1` "one newline at alternates: refused" and pinned by `W-505-b1` "a FIFO at alternates: refused" and pinned by `W-505-b1` "an empty info/attributes: refused".
