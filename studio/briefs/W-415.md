## Intent

D-119 replaces D-118's collapsed form. At 960 CSS px and wider, the existing shared left sidebar starts expanded when no valid preference exists and its top-left native button is the same 36px sidebar-panel icon in both states. Its exact accessible names are `Collapse sidebar` and `Expand sidebar`. Collapse leaves a restrained 48px icon rail: Inbox, Board, Seats and Officina remain as monochrome inline SVG links with one stroke style, native tooltips, accessible names and the current route marked. No dependency and no keyboard shortcut are added.

D-120 refines only the collapsed rail's Inbox alert. A nonzero count becomes one 16px notification dot at the Inbox icon's top-right; nothing else visible on the rail marks the alert. Its neutral surface uses the existing `surface` token, while its one-pixel outline and numeral use the already-ruled amber navigation-count token, so it is neither a red error nor an amber background. Zero removes the dot. The dot's accessible label retains the full count. The expanded sidebar stays exactly as signed: its existing inline Inbox numeral remains visible and uncapped.

Below 960px, the same shell becomes a closed overlay drawer; it never opens on hover. Pointer, Enter or Space on the top-left toggle opens it, moves focus to its first link and prevents the main pane behind it from scrolling. Escape or choosing a screen closes it and returns focus to the toggle. At phone widths the closed toggle remains inside the approved full-width 48px top row, with its 2px focus ring fully visible. The 960/959 classifier is responsive to live resize; the existing shell 599 breakpoint and Board 612/613 boundary remain.

D-119 retains D-118's wide preference. The browser key is `bisellium.sidebar`; valid values are exactly `collapsed` and `expanded`. An absent, invalid or unreadable value starts expanded and never crashes; writes that throw are ignored. Only the >=960px state writes the preference. A narrow overlay starts closed on mount and opening/closing it never overwrites the wide choice, which restores on reload and every route.

At a 1280px window, 200% zoom is represented by a 640 CSS-pixel viewport. Layout follows CSS viewport/container width on resize: no screen or document clips beyond the right edge and no page-level horizontal scroll appears. D-116's Board phase strip remains the one named local horizontal scroller; its CSS and JavaScript stay aligned at 612/613. At 640 the Board liveness row wraps before its project explanation compresses. At 390 Officina's text, counts and row labels shrink or wrap inside the main pane without redesign.

PR #758 rides this opus. `docs/design/DIRECTION.md` receives exactly its supplied red/amber/Inbox changes plus one navigation sentence naming D-119: red may be a blocked-card rule, amber is human waiting only, and Inbox expands its focused petitio in place with no detail pane. W-407, not this opus, builds that Inbox removal. Threat model: clipped or unreachable UI and inaccessible navigation state, not adversaries (D-045).
