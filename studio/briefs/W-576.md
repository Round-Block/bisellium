- **How "landed red" leaves master green (the code seam).** CI runs the served suite through `npm run -s test:serve --workspace @bisellium/web` (`.github/workflows/ci.yml:186-187`, the required `web-e2e` job at `:155`), and `verify`'s `served-e2e` gate runs the same command through `scripts/served-e2e.mjs:49-56`. - The marks use `test.fail(condition, description)` **inside** each case body, not `test.fail(title, fn)` and not `test.fixme`. There are two reasons.
