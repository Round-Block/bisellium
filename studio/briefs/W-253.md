# W-253 — retro reads only reviewer findings: an architect's spec signature never fails the retro

Status: **signed spec, revision 2** (review round 2: the W-221 triage step, the size bound) · written by the architect (`claude-opus-5-5`) under D-062 · 2026-10-14 · master 59776a34.

Read enumeration: none: no new record is read; `readOpusVerdicts` already lists and reads every `ci/<id>-spec-<n>.log`, and `designMagister` already reads the manifest for `reviewRounds`.

Red order: one at a time

## Intent

Decree family: retro-signature-notes

`bisellium retro --opus W-221 --from <triage>` refuses with `ci/W-221-spec-1.log: line under "## Findings" out of domain`. `readOpusVerdicts` (`packages/cli/src/retro.ts`), the retro's one reader of verdict logs, sends every `<id>-spec-<n>.log` to `parseVerdictLog`, whose findings grammar (`<n>. blocking|advisory …`) refuses the numbered signing notes the architect wrote in W-221's signatures (`spec-1`, `-3`, `-5`, `-6`, `-8`, `-9`, `-10`). A signature is not a review: `reviewRounds` in the same file already skips a spec log whose `# sella:` is the design magister. `readOpusVerdicts` follows the same rule. `next` holds every new opus while W-221's retro is owed (D-039 §1), so this fix lands first (D-062).

`check` is unaffected: its retro rules (`check.ts:326`, `rules/process.ts:310`) call `owedRetros`, which reads the setting and the actas, never verdict logs.

## Files owned

- `packages/cli/src/retro.ts`: `readOpusVerdicts` calls `designMagister(root)` once (a refusal is returned); a spec log whose header block (`headerBlock`) has `sella` equal to the magister is read through `readContainedRegularFile` and listed in `sources`, but it is not parsed and adds no findings. Review, build and handoff logs, and spec logs by any other seat, are read as today.
- `packages/cli/src/retro-opus.test.ts`: `W-253-b1`.

## Interfaces

`readOpusVerdicts(root, id): Verdicts | Refusal`: the signature unchanged. A signature's notes are not findings, so a triage entry naming one is refused as not recorded (the existing check).

### Input domain

A rejection fails closed: the retro exits 2 and writes nothing.

| Record | Valid domain | Rejected by |
|---|---|---|
| `bisellium.yml` design collegium | at most one row; when present, a non-empty `magister` | `designMagister`: anything else is a refusal (unchanged; now also on the `--opus` path) |
| A spec log signed by the magister | any contents, a contained regular file of at most `LOG_MAX_BYTES` (4,000,000 bytes) | `readContainedRegularFile`: a symlink, a non-file or a larger file refuses (unchanged); the body is not judged |
| Every other verdict log | `parseVerdictLog`'s grammar | `parseVerdictLog`: unchanged; with no design magister declared, every spec log is a review, as in `reviewRounds` |
