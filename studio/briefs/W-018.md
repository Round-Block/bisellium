# W-018 — The process as data: Design, spec, leges, decisions, lessons, retro

Builder C · collegium engineering · cascade 4b

## Intent

The studio model says a convention exists only if `check` can fail it. Four
things this repo runs on are still prose or habit: that work gets a spec before
it gets built, that a lex is a set of enforceable clauses rather than a wish
list, that a decision carries a kill condition, and that a cascade ends with a
retrospective that files lessons. Make all four data — files with front matter,
rules that fail them, and a command that drafts the retro from the cascade's own
numbers. Add the Design collegium the model has always listed and this studio
has never had.

You own `check.ts`, `new.ts` and `docs/ADOPTION.md`. Establish the rule-module
pattern the other two briefs' rules follow.

## The five pieces

**(1) Design and spec.** `studio/bisellium.yml` gains a `design` collegium
(magister `architect`, lex `leges/design.md`), a sella
`{ id: architect, collegium: design, kind: agent, model: claude-opus-5 }`, and

```yaml
  - { id: spec, name: Spec, kind: agent, since: 2026-09-18T19:00:00Z }
```

placed before `review` in the ladder. In the same edit add the four lines other
briefs depend on and cannot write themselves: `hooks: { default_sella: guest }`
(W-017); the `lint` probatio's `command: "npm run -s lint"` (W-019); a sella
`{ id: builder-d, collegium: engineering, kind: agent, model: claude-sonnet-5 }`;
and `wip_limit: 4`. Mirror the Design collegium into
`examples/sample-studio/bisellium.yml`.

**`since:` is the whole reason this is safe.** All fifteen `done` opera in
`studio/` would otherwise go red on `state.done.probationes`, and the only
escapes — backfilling spec gates, or writing briefs for done opera — are both
forbidden. So: a manifest probatio may declare `since: <ISO datetime>`
(`manifest.shape` blocks a non-string or unparseable value), and
`state.review.automated`, `state.review.agent` and `state.done.probationes`
**skip** a gate whose `since` is later than that opus's `traditio.at`. An opus
with a missing or unparseable `traditio.at` fails closed (the gate is demanded)
— `traditio` is already required on every active opus. W-001…W-015 hand off at
or before `2026-09-18T17:00Z`, so the `2026-09-18T19:00:00Z` cutoff exempts
them; W-016…W-019 hand off after it and are demanded. Document `since` in
`docs/ADOPTION.md` next to the ladder text ("`done` needs all non-human gates
passed") and amend that sentence to name the exemption.

New opus front-matter key `spec:` — an officina-relative path to
`briefs/<opus>.md`. `--spec <path>` sets it; `--brief` additionally creates
`briefs/<id>.md` from a template with the six sections this brief uses (Intent ·
Files owned · Interfaces · Behaviours to test · Acceptance · Out of scope) and
sets `spec:` to it.

Rule Rule `state.building.spec` (**block**): fires **only when the manifest declares
a probatio with id `spec`** — the six existing bad-* fixtures declare no such
probatio, so their EXPECT sets are untouched and `npm test` stays green. Where
it applies: an opus in `building`, `verifying` or `review` with no `spec:`, or
whose `spec` gate is not `passed`. Active states only; `done` and `halted` are
history. Write no briefs for done opera.

**Ordering.** `check`'s existing `probatio.declared` rule blocks a gate node the
manifest does not declare, so W-016…W-019 cannot carry a `spec` gate until your
manifest edit lands — they carry `spec:` and `probationes: {}` today, which is
green precisely because of the gating condition above. Integrator close step
**CS-1**, run immediately after merge and before `check`, writes
`spec: { status: passed, evidence: briefs/<id>.md }` onto the four opera via
`editOpusFrontMatter`. Do not write those gate nodes yourself, and do not
weaken `probatio.declared`.

**(2) Leges as leges.** Rewrite all four `studio/leges/*.md` from
`docs/LEX_TEMPLATE.md` into real charters: production (Aedile), design
(architect — §1 carries the definition of ready), engineering (Fabri: test-first
with a recorded red; mechanical work is a script; one opus owns its files; no new
dependency without a decision), qa (Censor: the first-hour drive; one mutation
per opus; block on writes outside the opus's declared files; owns the
retrospectio and may adopt an advisory rule alone).

Extend `LEX_TEMPLATE.md` with the clause convention: a clause `check` enforces
ends with `(check: <rule.id>)`. Rule `lex.unchecked` (**advise**, one finding
per lex, never per clause) reports the count of §2/§3/§4 clauses with no marker.

**(3) Decisions and lessons, in the contract.** Add to `docs/ADOPTION.md`:

```
decisions/D-nnn.md   {id, title, at, provenance: stated|observed|inferred|suggested,
                      by, kill_when, supersedes?}
lessons/L-nnn.md     {id, at, class: "<probatio>×<kind>", evidence: [...], cascade?}
```

Rules: `decision.shape` (**block** — missing/ill-typed key, id ≠ filename,
unknown `provenance`), `decision.kill` (**block** — `kill_when` missing or
empty; a decision with no kill condition is a belief), `lesson.shape`
(**block**), `lesson.evidence` (**block** — empty list or a dead relative href),
`lesson.recurrent` (**advise** — a `class` appearing in ≥2 distinct `cascade`
values on ≥2 distinct opera).

Write D-001…D-007 with honest provenance and real kill conditions. `[stated] by
patron`: the spec phase; retrospectio owned by the Censor; process is data; the
role vocabulary. `[observed]`: mechanical work is a script (C1b's 361k-token
hand edit); evidence is produced, never backfilled (C2's backfilled probatio).
`[inferred]`: certificates are judged for active opera only.

**(4) `bisellium retro --cascade N [--from <json>] [--studio dir] [--now <iso>]`.**
Drafts `acta/<date>-retro-<N>.md` (`kind: decision`, `author: qa-lead`,
`title: "Retrospectio N"`): numbers · findings by class · lessons filed ·
recurrence · proposals · pruning candidates. One `lessons/L-nnn.md` stub per
distinct finding class, with evidence hrefs.

**`retro` must never leave the officina blocking.** `lesson.evidence` is a block
rule, so `evidence` is **required and non-empty** on every `RetroFinding`, and
`draftRetro` refuses (exit 2, nothing written) an input with an empty list or a
href that does not exist under the officina, naming the offending class.

An advisory-rule proposal is marked *adopt alone*; a blocking-rule or lex-wording
proposal creates `petitiones/P-nnn.md` to the patron (`state: needs_you`).
Pruning candidates — decisions whose `kill_when` mentions a condition the input
shows as met — are **listed, never edited**.

**(5) The cascade as a committed template.** `cascades/cascade.js`: plain JS for
the Workflow tool, phases Spec → Build → Verify → Close-with-Retro, parameterized
by `{ opera: string[], now: string, repo: string }`. The architect phase reads
each opus's brief from the repo; each builder's prompt is "read `CLAUDE.md`, run
`bisellium context --sella <you> studio`, then your brief at
`studio/briefs/<opus>.md`". `cascades/README.md` explains how a cascade is
launched and what each role does.

## Behaviours to test

1. `state.building.spec` blocks an active opus with no `spec:`; clears when
   `spec:` is set **and** the `spec` gate is `passed`.
2. It never fires on `done`/`halted`, nor on any officina whose manifest
   declares no `spec` probatio — assert explicitly against a copy of
   `examples/fixtures/bad-wip-cap`.
3. `since:` — a `done` opus whose `traditio.at` precedes a gate's `since` emits
   no `state.done.probationes`; one whose `traditio.at` follows it does; an opus
   with no parseable `traditio.at` does. Same three for `state.review.*`.
4. `runNew --brief` creates `briefs/<id>.md` with all six sections and sets
   `spec:`. `--spec briefs/W-016.md` is **accepted**; an absolute path, any
   `..` segment, and any value resolving outside the officina are refused
   (exit 1, nothing written). Existing `new` flags and exit codes are unchanged.
5. `lex.unchecked` reports the exact clause count for a fixture lex and emits
   one finding per lex.
6. `decision.shape` blocks each missing key in turn, and an unknown `provenance`.
7. `decision.kill` blocks an empty `kill_when`.
8. `lesson.shape` and `lesson.evidence` block missing keys and a dead href.
9. `lesson.recurrent` advises only at ≥2 distinct cascades on ≥2 distinct opera.
10. `draftRetro`: every named section present; one lesson stub per distinct
    class; a petitio for a blocking-rule proposal and none for an advisory one;
    a pruning candidate listed with the decision byte-identical on disk; and
    `check` on the officina afterwards reports **zero new blocking findings**.
11. `draftRetro` exits 2 on a finding with an empty or dead `evidence` list.
12. `retro` is deterministic under a pinned `--now`.
13. `cascades/cascade.js` parses as a module and its exported phase list is
    `["spec","build","verify","close"]`.

Record the red for each.
