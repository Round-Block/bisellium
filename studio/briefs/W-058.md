# W-058 — red refuses inactive opera: state and ownership guard on runRed

## Intent

Pointer, filed under P-010 from Sol's red-team of W-039 (should-fix 3).
`runRed` (`packages/commands/src/lifecycle.ts:485`) checks neither that
the opus exists, nor its state, nor who owns it. So `bisellium red` can
write `ci/reds/<id>/NN.log` into a `done` or `halted` opus. That includes
an explicit `--sella guest` red, which W-039 accepts, and which W-039's
`opus.red_sella` rule never sees because it walks only active opera.
W-033 left `red` out of the ownership guard on purpose
(`studio/briefs/W-033.md`, "Not guarded"), so changing that is a contract
change and needs its own opus. It should not ride in W-039. Needs a spec
before greenlight.
