## Intent

Current master already has most of the drawer interaction. The Board owns one pushed, non-modal drawer, opens it from lifecycle cards and the Waiting-on-you strip, fetches its events, moves focus to Close, and restores focus and horizontal offsets when it closes. The Inbox already labels Board-owned attention rows and hands their opus ids to `App`, which mounts that same drawer. Evidence is `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/src/screens/Board.tsx`, `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/src/screens/InboxView.tsx` and `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/src/App.tsx`. W-451 keeps all of that and does not restyle or rebuild the drawer.

What master does not hold is a durable location. `parseRoute` recognises only bare `#/board`; Inbox stores the selected opus in transient `pendingBoardOpus` state and changes the hash only to `#/board`; a reload or pasted `#/board/W-004` therefore cannot reopen the drawer. The existing initial-selection path also admits only attention entries, not every returned opus. Evidence is `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/src/lib/route.ts`, `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/src/App.tsx` and `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/src/screens/Board.tsx` at 1fb5430a. Make the hash the drawer's location: an exact `#/board/W-N` selects that existing `/api/opera` entry, card and Inbox openings write the same canonical href, browser Back and Forward close and reopen it, and explicit Close replaces the deep hash with `#/board`. A syntactically valid id absent after the Board's complete reconciliation says `Work item W-N was not found.` and opens no drawer. A malformed Board target says `That Board link is not valid.` on the mounted Board.

Master also already has W-415's click-only narrow overlay, active-page `aria-current`, Escape dismissal, navigation dismissal, fixed toggle position and focus return to the toggle. Its opening path still focuses the first link, Inbox, and W-415-b3 pins that obsolete behavior. Evidence is `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/src/components/Sidebar.tsx`, `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/test/w415.test.ts` and `/home/edckt/agents/bisellium/.worktrees/W-451-re/apps/web/tests-serve/w415.spec.ts` at 1fb5430a. Under D-134, opening below 960px instead focuses the sole link carrying `aria-current="page"`; the existing dismissal and geometry rules remain.

D-175 makes this only Piece 1. It adds no Home route, default route, Home model, palette, dashboard card, Queue lane, Completion, Spend or Time surface. DIRECTION's drawer rule remains, while D-151's Board-owned Inbox action gains the durable destination and D-134 overrides the first-link focus assumption.
