# W-016 — Server and core correctness (cascade-4 review)

Builder A · collegium engineering · cascade 4b

## Intent

Cascade 4 shipped `apps/server`, `packages/core`'s index and the hook profile
in one window, and the review found the three do not meet. The server
re-implemented ingest, so the SQLite index is dead code; `/api/events` and
`/api/live` serve a construction-time array; POST routes treat loopback as
authentication; `packages/cli` and `@bisellium/server` import each other.
Fix all of it: the index becomes the read path, the live log is live, a write
needs a token, and the dependency graph is a DAG.

Nothing here changes the on-disk contract (`EVENTS_LOG_REL`,
`SNAPSHOTS_DIR_REL`, `INDEX_DB_REL`, route shapes, exit codes). It changes who
computes what.

`claudeCodeHooksBlock({ studio })` with `sella` omitted must emit commands
carrying **no** `--sella` flag (strip the flag *and* its placeholder from the
template text, do not substitute an empty string). `hook-event` then resolves
the sella as `--sella` → `process.env.BISELLIUM_SELLA` → manifest
`hooks.default_sella` → `"guest"`. W-017 commits a `.claude/settings.json`
that this must match; see the seam note in that brief.

Moving `query.ts` and `context.ts` is not optional. `talk.ts` imports
`./query.js` and `./context.js` (lines 24–25); leaving them in `packages/cli`
relocates the cycle rather than cutting it. Neither imports `check.ts` — only
`@bisellium/adapter-native` and `@bisellium/core` — so the move is clean.

## Behaviours to test

Each is a test with a recorded red captured before the fix. Hermetic: temp
copies of `examples/sample-studio`, the `fake` harness, port 0, pinned clock
`2026-09-18T20:00:00Z`.

1. `apps/server`'s store **is** `@bisellium/core`'s `Store`. After
   `startServer` on a studio with no `.bisellium/`,
   `<studio>/.bisellium/index/index.db` exists and `store.query.opera()`
   returns the studio's opera.
2. `bisellium query --from-index` on a studio with no index creates one and
   answers from it (the file fallback stays, but first use builds the index).
3. `/api/events` reflects a write made **after** start: append via the
   injected `answer`/`emit` runner, force a poll, and the new event appears
   without a restart. Same for `/api/live`.
4. Event `seq` comes from the Store's sequence, never `log.length`: two
   sources appending interleaved yield strictly increasing, non-colliding
   `seq` across `/api/events`.
5. POST `/api/greenlight`: valid token + `Origin: https://evil.test` → 403;
   no Origin, no token → 401; token + `Content-Type: text/plain` → 415;
   no Origin + `application/json` + token → 200. Loopback alone never
   authorizes.
6. A POST body over the cap gets **413** with a JSON body (today the socket
   is destroyed and the client sees a hangup).
7. `?limit=-5`, `0`, `99999`, `abc` on `/api/events` and
   `/api/timeline/:sella` clamp into `[1, 500]` and never throw.
8. SSE: exactly one `store.on("event")` listener with three clients connected
   (`store.listenerCount("event") === 1`). A client past `MAX_SSE_CLIENTS`
   gets 503. A client whose socket errors is dropped via `res.on("error")`
   without taking the server down. A slow client whose `res.write()` returns
   `false` is not written to again until `drain` and does not block the others.
9. Static containment uses `path.relative(WEB_DIST, filePath)`: a request
   resolving to a sibling sharing the prefix (`.../web-dist-evil/x`) is 403.
10. `bisellium query --from-index` appends **nothing** to
    `.bisellium/events.jsonl` (byte-compare) and closes its sqlite handle.
11. The cycle is gone, asserted structurally: `apps/server/package.json` has
    no `@bisellium/cli` or `@bisellium/commands` dependency; a module-graph
    walk from `apps/server/src/index.ts` (resolve relative + workspace
    specifiers, follow transitively) reaches neither package. A grep for the
    string alone is not sufficient evidence — it passes over a cycle reached
    through a third module.
12. Hook contract: `bisellium hook-event context --sella eng-lead` exits 0
    within 2s on a broken studio, a missing studio and a healthy one, and
    prints the boot bundle on **stdout**. The printed profile uses
    `hook-event context` for SessionStart and PreCompact, and every `timeout`
    in it is `2`.
13. `hook-event tool` does not read the whole log: with 5,000 lines in
    `events.jsonl` it finishes under 300ms and appends exactly one line. Its
    `workflow.tool_used` payload redacts `cwd` the way `file_path` already is.
14. `claudeCodeHooksBlock({ studio: "studio" })` typechecks with no `sella`
    and no printed command contains `--sella`; with `{ sella: "eng-lead" }`
    every command still carries `--sella 'eng-lead'` (the existing profile
    test must stay green).
15. No dead imports: the moved and rewritten modules compile under
    `noUnusedLocals`/`noUnusedParameters` (record that run as evidence; W-019's
    lint enforces it repo-wide afterwards).
