## Intent

Class `tests×ruled-case-uncovered` (D-076 D, high, D-039) recurred after its cause fix W-322. W-335's build review round 1 (`studio/ci/W-335-review-1.log`, S1) found a checkout path holding a space split NODE_OPTIONS' `--import`: the brief ruled the wrapper's checkout (its Interfaces 1) and listed no hostile-but-valid form of its path, so no test held one, and the review named one lawfully. W-322 made each Input domain row name its pinning test, and D-085 D made a row whose Valid domain is any text list the forms it recognises and call every other form a limit. A row whose valid domain is a filesystem path, a command line or an environment value is the same loop with a known first move: a space, a quote, a non-ASCII name and a symlinked parent are valid, ordinary and each breaks a different naive reader.

After this opus W-322's ledger check reads one more kind of row, for the design magister's spec signature. A row is path-typed when its Valid domain cell holds one of a fixed vocabulary of words (Interfaces). A path-typed row holds W-322's forms clause ("recognises", at least one form, "every other form", "limit"), and each line its clause cites holds a pin, as for an any-text row. Its line, or a line its clause cites, also names each of the four forms by its word: space, quote, non-ASCII, symlink; a form named there is either a recognised form, pinned with that line, or a stated limit after "every other form". The writer refuses the signature otherwise, one problem per gap. One reader (`ruledCases` in `brief-admission.ts`) serves the writer and, unchanged, the build packet; no new verb, no new file format.

Why the signature check and not brief admission (the record names both): W-322 put the any-text rule in the signature check alone, and extending it there keeps one mechanism (D-042). Admission runs on every signed brief that next reads, so the rule there would send back briefs already signed: on master the prototype's reader finds 100 path-typed rows with a gap in 45 briefs, every one of them naming no quote (`census.out`). The signature check judges only new signatures.

Why a fixed vocabulary in the Valid domain cell: it is the cell W-322's any-text trigger reads, and a column word would add a fourth column every tabled brief lacks (`DOMAIN_COLUMNS`, W-322 Out of scope). The vocabulary census (`census-vocab.out`, 639 rows in 69 briefs) shows `path` in 66 Valid domain cells, `directory` in 29, `argument` in 11 and `command line` and `environment` in one each; `file` (123) is left out, since a file row rules its bytes, not its name.

What it does not catch: W-335's checkout was ruled in Interfaces prose, not in a row, and its NODE_OPTIONS row's Valid domain says "none, or any values"; the rule reads rows and words, so neither would have been judged (Limits). It makes the first move cheap and visible at signing; the spec review keeps the rest.

Threat model: mistakes, not adversaries (D-045).

## Interfaces

The prototype is `apply-src.py <checkout> <1|2>` (stage 2 includes stage 1 and the `docs/VERBS.md` paragraph) and the rows are `apply-test.py <checkout>`, staged by `stages.sh <master|s1|proto>`. `prototype-src.diff` and `prototype-test.diff` are the whole diff on master 776f751e. `ruledCases(briefText: string): { cases: RuledCase[]; formless: number[]; pathGaps: PathGap[] }` (W-322, extended). For each row, after its own case: when its Valid domain cell is any text or path-typed, its forms clause is read as W-322 reads it, and each line the clause cites is a case of that row; `formless` holds the any-text rows with no clause, as before. `pathGaps` holds, in row order, each path-typed row with no clause (`formless: true`, unless it is an any-text row, which is in `formless` already) or whose text does not name every form (`missing`, in the order space, quote, non-ASCII, symlink). `PathGap` is `{ row, formless, missing: string[] }`. The build packet reads `.cases` only, so it now lists a path-typed row's cited lines too; its code is unchanged.

The forms `ruledCases` recognises for a path-typed row, one per line (each is a grammar line of Input domain row 2):

- the trigger: one of the words path, paths, directory, directories, command line, command lines, command-line, argv, argument, arguments or environment, whole (no word character or `-` on either side), any case, in the row's second cell (Valid domain) only — pinned by `W-336-b1` "row with no forms clause" and pinned by `W-336-b1` "path in a Rejected by cell only"
- the forms clause and its cited lines: W-322's, unchanged (its forms clause and grammar citation lines in `studio/briefs/W-322.md`), each cited line holding a pin of its own; an any-text row that is also path-typed and has no clause has W-322's problem only — pinned by `W-336-b1` "a clause with no form" and pinned by `W-336-b1` "a cited line of a path row with no pin" and pinned by `W-336-b1` "the any-text problem only"
- the hostile words, whole, any case: `space`, `spaces` or `whitespace`; `quote`, `quotes` or `quoted`; `non-ASCII`; `symlink`, `symlinks` or `symlinked` — pinned by `W-336-b2` "not named" and pinned by `W-336-b2` "names nothing" and pinned by `W-336-b2` "name the forms"
- where they are read: the row's real line (fences and HTML comments blanked), anywhere on it, and each line its clause cites (between "recognises" and "every other form"); a line cited after "every other form", and a line not cited, are not read — pinned by `W-336-b2` "a form named on a cited grammar line" and pinned by `W-336-b2` "a form named on a line cited after every other form"

Every other form is a limit: a path ruled in other words (a checkout, a worktree, a cwd, `$HOME`, `pathname`, `file-path`, a variable named only by its name such as NODE_OPTIONS), a row ruling a file by its bytes (`a regular file`), a hostile form named in other words (Unicode, an apostrophe, a link, a tab), a form word that names the form only to deny it, and a word run into another (`namespace`, `unquoted`). Ordinary edits in a listed form stay inside the domain: prose round the words, any case, a form named in any cell.

`promiseLedgerProblems(brief, transcript, briefRel)` (W-306, W-319, W-322) gains, after W-322's formless problems and only once a ledger is cited, for each path gap in row order:

1. when `formless`: `brief:<n> rules a path, a command line or an environment value and lists no forms: say "recognises", then the forms (code spans, or brief:<line> citations of the lines that list them), then "every other form" and "limit"`;
2. then, when `missing` is not empty: `brief:<n> rules a path, a command line or an environment value and does not name <missing, joined by ", ">: name each by the word space, quote, non-ASCII or symlink, on the row or on a line its forms clause cites, as a recognised form with its pin or as a stated limit`, the forms named `a space`, `a quote`, `a non-ASCII name`, `a symlinked parent`.

`runVerdict` is unchanged: each problem prints as `<id>: promise ledger: <problem>`, and the writer exits 2 with no log written and the ticket unclaimed.

The `docs/VERBS.md` paragraph (`prototype-src.diff`) states the rule and its limits.

Promise path-forms: a spec signature by the design magister is recorded only when each Input domain row whose Valid domain cell holds a word of the vocabulary holds a forms clause, each line the clause cites holds a pin, and the row's line or a cited line names a space, a quote, a non-ASCII name and a symlinked parent by their words — limit: the trigger and the forms are words, so a row ruling a path in other words needs no clause, a form named only to deny it counts, and whether a named form is pinned or stated as a limit is not judged; the four are a floor, and a forms list's completeness stays the spec review's (D-085 E).

Promise one-problem-each: each gap is one problem, after W-322's, a missing clause before the missing forms, and the signature is refused with no log — limit: the refusal is `runVerdict`'s, reused unchanged.

Limits, stated:

- Only new signatures are judged; recorded signatures are not re-read. On master 100 path-typed rows in 45 briefs have a gap (`census.out`); a brief signed again names its forms then.
- A path ruled outside the Input domain table (W-335's checkout, in its Interfaces 1) is not judged: the rule reads rows, as W-319 and W-322 do.
- Unchanged code the promises lean on is a stated limit, not a guarantee (D-076 E): `realLines`, `inputDomainRows`, `cellsOf`, `FORMS`, `GRAMMAR_CITE` and the clamp, `ANY_TEXT`, W-306's, W-319's and W-322's ledger reader and problems (`CITATION_TOKEN`, `STATUS`, `SCOPED`, the counting rule, `readDesignMagister`), `runVerdict`'s refusal order, `readContainedRegularFile`, and `scripts/review-packet.mjs`'s `pinFact`, which now lists a path-typed row's cited lines through the same `.cases`.
