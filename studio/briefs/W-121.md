## Intent

Patron, on P-015 (2026-10-01): build the check; a test that waits on wall-clock
sleep where a synchronisation seam is missing is a blocking finding. The class
`tests×wall-clock-sleep-for-a-missing-seam` was filed by retro in cascade 32
(L-035) and again in cascade 35 (L-050), and the live offender has cost at least
three PR round-trips (139, 153, and one on 2026-10-01).

**The live offender, root cause.** `scripts/no-vendor.test.mjs` behaviour 9 row 3
asserts "the lock was never free before A had already produced its (correct)
result". A is a separate process whose script is `runOnce(...)` followed by
`writeFileSync(aResultPath, ...)`. `runOnce` releases the lock in its `finally`,
which runs when it *returns*, so the lock is legitimately free for the interval
between A's `releaseLock` and A's own `writeFileSync` of the result file. The
test polls the lock with a 1 ms `setTimeout` loop and sets `racedEarly` when the
lock is free and the result file is absent. Whenever the poll lands in that
interval (a loaded CI runner makes it wide) the row fails with a correct
implementation (`attempts=NN` in the detail). The test's "result produced"
signal is, by construction, emitted *after* the event it is ordered against, so
no amount of tuning the sleep fixes it. The missing seam is a point inside A,
after adjudication and before release, where A can say "I am about to release"
and wait.

**Two halves, one decree family.** (1) the check rule; (2) the repairs that make
the tree pass it. They are one family: the rule is blocking, so merging it
without the repairs turns master red, and the repairs have no reason to exist
without the rule. Split per W-127's rule (not yet built, honoured here) is
therefore **not** warranted. What is a follow-on, not folded in, is named under
"Follow-on filings".

**Blocking at once, not advisory first.** The decree says blocking; the tree is
made to pass in this same opus, so there is no window in which master carries a
violating test; and an advisory stage is a second state with a second PR and a
second place for the class to recur (it has already recurred twice across
cascades while only a retro class existed). The ratchet is the annotation grammar
below, not a delay.

## Interfaces

### The rule: `test.sleep`, level **block**

New module `packages/cli/src/rules/tests.ts` exporting `checkTests(root, opts):
Finding[]` (Seam S2: `root` the officina, `opts.repo` the repo root). Wired in
`check.ts` beside `checkEvidence`. Registered in `rules/ids.ts` as `"test.sleep"`
(the drift guard in `rules/lex.test.ts` re-harvests the literal). Never throws; `[]`
when `opts.repo` is absent, when `git` is unavailable or fails, or on timeout
(the house "a rule that can't observe says nothing" shape of `rules/evidence.ts`).
It reads, never writes; file contents are data.

**File set.** `git ls-files -z` in `opts.repo` (tracked files only; an untracked
test file is unseen until `git add`, a stated residual). A path is scanned when
all hold, on its repo-relative POSIX form:

1. its extension is one of `.ts .tsx .mts .cts .js .mjs .cjs`;
2. it is a test file: the basename matches `\.(test|spec)\.[cm]?[tj]sx?$`, OR any
   directory segment is `test`, `tests` or `tests-serve`;
3. no segment is `node_modules` or `fixtures`;
4. it is a regular file (`lstat`, never a symlink) of at most 1 MiB.

**Sleep-primitive grammar** (applied per line; lines whose trimmed text starts
with `//`, `*` or `/*` are skipped; a line yields at most one finding):

| Primitive | Pattern | Note |
| --- | --- | --- |
| timer | `(?<![.\w])setTimeout\s*\(` | member calls (`test.setTimeout(`, `sock.setTimeout(`) are not sleeps |
| interval | `(?<![.\w])setInterval\s*\(` | |
| playwright | `\bwaitForTimeout\s*\(` | |
| atomics | `\bAtomics\.wait\s*\(` | |
| sleep | `(?<![.\w])sleep\s*\(` | |

Matches inside string literals count (builder fixtures are strings); the
annotation then goes on the preceding comment line.

**Annotation grammar.** A site is covered by exactly one `//` line comment on the
same line (trailing) or on the immediately preceding line, which must be a
comment-only line. Block comments do not annotate.

```text
// sleep-seam: <name> -- <what the wait exits on, >= 15 characters>
// sleep-waiver: <kind> -- <why no seam can exist here, >= 15 characters>
```

- `<name>` matches `[A-Za-z_/][A-Za-z0-9_./-]{2,}` and must also occur in the file
  outside annotation comment lines (declared and used; a typo or a vacuous name is a
  finding). `sleep-seam` means: the wait is on a named observable (barrier,
  marker, event, predicate) and the sleep is only the poll cadence.
- `<kind>` is exactly one of `guard` (a deadline that fails the test or kills a
  fixture, not what correctness waits on), `subject` (the elapsed time is the
  property under test), `fixture` (a keep-alive or injected-latency fixture),
  `no-observable` (an ordering or absence window with no observable; the reason must
  name what is missing). **`settle` is deliberately not a kind**: "let it settle" is
  the class itself.

**Finding.** `rule: "test.sleep"`, `level: "block"`, `where: "<path>:<line>"`,
message names the primitive and either "no annotation" or the defect (unknown
kind, reason too short, name not used elsewhere in the file, annotation not on the
same or preceding line). Annotations that cover no site are ignored (no finding).

### The seam for the live offender

`scripts/no-vendor.mjs`: `runOnce(opts)` gains an optional `opts.beforeRelease`
function. It is called **once, synchronously, in the `finally`, immediately before
the guarded `releaseLock`, iff this call acquired the lock** (not on the
refused-lock path, where the lock is another run's). It receives no arguments and
changes no result. Production callers do not pass it; there is no env var and no
CLI surface (unlike W-101's barrier, `runOnce` is called in-process by the test's own
script, so an option suffices).

`scripts/no-vendor.test.mjs` row 3 is rewritten with no timer and no poll:
A's script passes `beforeRelease` that writes a line to its stdout (a pipe to the
test) and then blocks in a syscall until the test closes A's stdin
(`readFileSync(0)`; a FIFO opened for read is the stated fallback if the platform
returns EAGAIN). The test awaits, with events only, whichever of A's stdout line
or A's `exit` comes first (a crashed A is reported, never hung on). On the line
the test attempts `openSync(lockPath, "wx")`: it must throw EEXIST (the lock is
held through adjudication, A frozen before release). It then ends A's stdin,
awaits `exit`, and asserts A's result contains `row3-violation` and the lock file
is gone. No `racedEarly` flag exists any more; the invariant "released last" is
checked at the one instant where it can be, deterministically.

## Stated residuals (accepted, with reason)

1. **The rule proves declaration, not truth.** It cannot tell a real seam from a
   named one; the censor judges the annotations, and the waiver caps in behaviour 5
   keep the count visible. The alternative (semantic detection of races) is not
   mechanical.
2. **Untracked test files are unseen** until `git add`; CI scans the committed tree.
3. **Busy-waits and elapsed-time assertions** (`Date.now()` loops with no timer,
   `performance.now()` deltas) are outside the grammar (see Measured present state).
4. **A sleep spelled outside the grammar** (a promisified `setTimeout` bound to
   another name, an imported `sleep` helper under another name, a shell `sleep`
   in a string handed to `sh`) is not seen. Accepted; widening the grammar needs a
   census of real cases first.
5. **Playwright specs are annotated, not rewritten**: they are not in `npm test` and
   cannot be replayed in the builder runtime.
6. **No `opus.red_assertion` coverage of the TAP form** (pinned to W-096), as in
   W-124.
7. **Sites that move.** The line numbers above are at `41d64dd`; the rule's output,
   not the table, is the builder's work list.

If, during phase 2, a REPAIR site proves to need a production observable (a change
to a module this brief does not own), the builder stops on that site and escalates
to the architect for a scope ruling; it does not reclassify it as a `settle`-style
waiver, because no such kind exists.
