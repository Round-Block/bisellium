## Intent

`W-406-b3` (`apps/web/tests-serve/w406.spec.ts`, "Officina today rule clears the last day letter at 1280 and 390") measures the fasti strip's today column: the 1px today rule must not overlap the weekday letter under it. The producer's diagnosis holds, with one addition the host found:

- **The weekday.** The today column is the strip's last 12px column (`buildFastiColumns`), and the rule sits at its trailing edge (`right: 0`, W-406). The letter is centred. Pinned to each day of one week (`probe-master.out`), the letter box in Instrument Sans at 11px is S, T, F 7px wide (right edge 1.5px clear of the rule), M 10px (it ends exactly at the rule, separated only by the row's 0.5px tolerance), and W 12px: it fills the column and overlaps the rule at both 1280 and 390. 2026-10-28 is a Wednesday, so the row fails every run that day and passes the other six.
- **The font.** `--font-body` is a web font with `font-display: block`. The row measures as soon as the Officina is visible, and a box taken before the font loads has fallback metrics (`probe-fonts-proto.out`: F at 1280 measured 6.328px wide before the load and 7.000px after it). So the row can also pass on a Wednesday: the first prototype of `W-442-b1`, with no font wait, passed on master once (`r0/red-b1.out`), most likely measured before the font loaded, and the record's "passed PR 827's minutes later" fits the same race. With the wait it fails on master every run.

This opus does one thing, a behaviour: the today rule moves into the 4px gap after the today column (`right: -2px`), 1px clear of the column's edge, so it clears the widest letter on every weekday at both widths in the repository font (`probe-proto.out`). A new served row `W-442-b1` pins the browser clock to each day of one week and waits for the letter's web font before it measures, so it is deterministic: on master it fails at the Wednesday, every run (`red-b1.out` and its repeats). `W-406-b3`'s served row stops reading the real clock: it is pinned to the Wednesday, the widest letter. Its policy row's CSS assertion follows the new inset.

Threat model: a layout regression and a flaky gate, not adversaries (D-045).
