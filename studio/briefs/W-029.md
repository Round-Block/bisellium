# W-029 — playwright: UI integration tests for web app

## Intent

Static rendering tests (`apps/web/test/*.test.ts`) verify structure but not
interaction — click handlers, keyboard navigation, route transitions. W-029
adds Playwright as the integration test runner for `apps/web`, with a
minimal smoke suite covering the two shipped screens (Inbox, Officina).

## Files owned

- `apps/web/playwright.config.ts` — Playwright config (baseURL from vite dev)
- `apps/web/tests/smoke.spec.ts` — smoke tests for navigation and interaction
- `studio/briefs/W-029.md` — this file

## Interfaces

- `npm run test:e2e` script in `apps/web/package.json` — runs Playwright
- Playwright config uses `webServer` to start vite dev before tests

## Behaviours to test

1. Inbox screen loads and shows the heading
2. Nav links switch between Inbox and Officina screens
3. Keyboard navigation (j/k) works on inbox items (if any exist)
4. Officina screen loads and shows fasti strip
5. Route hash changes reflect in the displayed screen

## Acceptance

`npm run test:e2e` in `apps/web` passes with Playwright running against
the vite dev server. Tests cover both screens and at least one interaction.

## Out of scope

- Full interaction coverage (drawer open/close, verb buttons)
- CI integration (Playwright in GitHub Actions)
- Visual regression testing
