On 2026-11-01 the PreToolUse background guard refused a ladder-runner Bash call that wrote a checkpoint script by heredoc: the script text held HTML entities (mdash, middot), and the guard pattern matches an ampersand anywhere in the command, so a call with no background work was refused as one. Fix: the guard refuses only a trailing or separating ampersand outside quotes and heredoc bodies, and nohup, setsid or disown as commands; quoted or heredoc text never matches. Rows: a heredoc holding an HTML entity passes; a real trailing ampersand is refused.
