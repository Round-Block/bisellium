Retro 11-10 (hook x backgrounded-subshell): a ladder-runner used "( ... ) &" once, so no exit file was written; guard.test.ts has no row for a subshell group followed by &. Rule: the guard refuses "( cmd ) &" in a foreground Bash call and in a run_in_background call too, since the harness already detaches it and an inner & loses the exit code. Red rows: both forms refused; a quoted "( x ) &" inside an echo and a heredoc body allowed. Fold into W-537 instead if its template already pins the background form. Owner ops-lead. Held by D-178.
