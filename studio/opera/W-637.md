Patron 2026-11-13 (W-503 rebase): a rebased opus branch stops for the Patron's look only when master's change touches the prototype's own diff hunks or the CSS selectors it adds or edits; any other master change (an additive rule elsewhere in a shared file) proceeds with the re-sign. Today D-202's rule stops on any non-empty prototype-path diff. A check rule (or next's rebase step) compares master's diff against the prototype's hunks and selectors and names the overlap, or none.
