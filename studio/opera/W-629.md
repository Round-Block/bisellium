2026-11-13: a ladder-runner whose background review run had exited 0 (TaskStop: not running, status completed) was refused three new background calls by the PreToolUse guard: "your background run <id> is still live, and an agent keeps one background run at a time (W-494)". The guard's record of the agent's background run is not cleared when the run ends. Fix: clear (or re-check) the record on the run's completion; pin with a hook-event row where a finished run is followed by a new background call.
