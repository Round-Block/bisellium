W-494 one-background-run guard: a ladder-runner that hands back mid-run and is resumed (SendMessage) keeps its finished background run counted as live, so its next background call is refused; a fresh runner works. Reproduced twice on 11-12 (W-604, W-608 ladders). The guard should clear a run whose exit was delivered, keyed per agent, with a test that resumes an agent after its run exits.
