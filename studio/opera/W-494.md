On 2026-11-01 ladder-runners piled up background shells: W-452's runner left 11 `until grep merge-452.out` waiters and W-487's runners several more, 14+ tasks at once. Cause: the SubagentStop hook (W-310) sends an agent back while it has background work and made one stop its own `ci --opus` run, so runners stay in turn by starting a new background waiter on every wake; nothing refuses a second waiter on the same file or a background loop while another of the agent's runs is live. Fix: the PreToolUse guard refuses a background Bash call from a subagent that already has one live background task (one run per agent), and briefs and the ladder-runner definition say to wait with foreground polls (`timeout 540 bash -c 'until [ -f X.exit ]; …'`); W-310's hook allows ending a turn while the one tracked run is live. Also: the main thread named runners for their first job and reused them, so task labels misled the Patron.
