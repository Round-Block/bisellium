W-562's stated limit (brief Limits), from the leads' codex-sandbox meet 2026-11-09 call 1: Codex 0.167.0 could not run its read-only shell inside our sandbox and a review recorded a blind PASS. Rule: a check rule (or perform precondition) compares the installed codex --version with the pinned version and refuses a Codex review step when they differ unless a kept smoke log for that version exists (codex exec -s read-only lists and reads a worktree file inside our sandbox; kit ~/.bisellium-evidence/codex-smoke-1109/pin/run.sh), so an upgrade is admitted only by a kept smoke run. Red rows: an unpinned version with no smoke log is refused; with a passing smoke log it is admitted.
