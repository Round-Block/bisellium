Patron 11-01. next's fixedOutside (D-086 B, W-328) counts only commits outside the officina as a failed build-review round's fix, so a fix that changes only studio/bisellium.yml leaves the source tree and brief unchanged and next re-orders a builder forever: W-452 review round 1's S1 fix ccc2c52c (spec_seats.since pinned) is held that way. A commit after the failed round's log that changes the manifest (the officina's bisellium.yml, which decides behaviour, unlike opera, ci logs and receipts) counts as a fix commit and next orders the next review round. Bookkeeping-only commits still do not. W-452 waits on this opus.
