# Slate ranking, 2026-09-25

This acta is the source of record for the order of the slate until a later
ranking acta replaces it. It supersedes `acta/2026-09-24-ranking.md`, which
stays on disk as history: of its fourteen ranked items, eleven have landed or
been overtaken, and eighteen opera have been filed since. The backlog page
(W-041) shows the inputs — state, blockers, gates — and does not rank.

Judged against the records as they stood on 2026-09-25 (29 open opera: 22
ranked here, 4 on the UI track, 3 halted). The rule is the production lex
§2: **rank by long-term positive gain — compounding value to the process and
the product outranks one-off convenience** (Patron's decree, 2026-09-20,
P-010). Where two items are close, the tiebreak is the same one W-049 won
last week: a guard that cannot be forgotten beats a feature that must be
remembered.

**Two tracks run in parallel.** This acta orders the **engineering track**.
The **UI track** is ordered by decree and listed separately below; UI/UX is
the Patron's call, not this acta's. One serial Claude stream at a time, with
codex lanes alongside (D-020).

## Order — engineering track

1. **W-072**, the vendor-spend sentinel. `npm test` can invoke a real vendor
   binary, so every test run is a lottery ticket against the Patron's
   allowance and a source of non-deterministic greens; a prototype already
   exists, L-030 already names the target, and nothing may dispatch W-061
   before this guard is in place.
2. **W-059**, nine raw id-to-path joins bypass `safeItemPath`. The
   containment class has failed review on three separate opera and the
   engineering lex already forbids it in prose — closing it at every site
   once is strictly cheaper than catching it one opus at a time forever, and
   it is the security class with the widest blast radius on disk.
3. **W-062**, the `amend` verb (spec written today,
   `studio/briefs/W-062.md`). Two live hand edits of `opera/` front matter
   this week, both forced by no-verb-exists, and the censor has declared the
   third an escalation (C7, `ci/W-075-review-1.log:351`); it removes a
   standing invitation to break "never by hand" and it shrinks W-040 on the
   way past.
4. **W-060**, `classifyAddressedTarget` falls through to `rule` for any
   unmatched target. A typo or a deleted opus currently reads as
   *addressed*, which means the retro — the process's own feedback loop — is
   quietly reporting work as closed that nothing closed; a silent wrong
   answer in the accounting outranks every loud breakage below it.
5. **W-057**, the server stops leaking stack traces (GHAS alert 3). An open
   security alert on exactly the surface W-070 is about to publish beyond
   localhost; a fix of this class is worth most *before* exposure, and
   paying for it after would be the expensive order.
6. **W-068**, a `depends` field and its check rule. It turns sequencing from
   an architect's prose judgement — this acta — into something `check`
   refuses, which is CLAUDE.md's standing rule (process enforcement is a
   check rule or a hook, never a memory or prose) applied to the one
   process document that is still prose.
7. **W-066**, `talk`'s claude resume path. Resume of a recorded session
   returns "No conversation found" **and the vendor error never reaches the
   operator** — the second clause is the compounding one: a transport that
   swallows its own diagnostics will cost a debugging session every time any
   vendor changes anything.
8. **W-048**, a red's command must be repo-runnable. Three red-provenance
   classes surfaced in reviews this week (C1 backfilled, C5
   reproducible-pre-fix, C7's neighbour A5); a red whose command names a
   scratch path is not evidence a third party can re-run, and the whole
   evidence contract rests on that property.
9. **W-058**, `red` refuses inactive opera. Same evidence-integrity family
   as W-048 and cheap beside it: a red recorded against a `done` or
   `backlog` opus is provenance for nothing, and the guard belongs at the
   one writer.
10. **W-061**, one opus end-to-end on both providers. The largest remaining
    item and the biggest structural prize — it is what lets bounded work
    leave the Claude stream (throttle order, D-020) — but W-046 delivered
    only the talk-shaped half, and dispatching the opus-shaped half before
    W-072's sentinel exists would spend real vendor money in a test suite.
11. **W-063**, the backlog page shows in-flight opera. D-021's own named
    consequence: with `ready` on the branch, trunk shows `greenlit` for work
    that is building, so the page that feeds every ranking is wrong about
    the present. The producer's file, not engineering's — it can run in a
    codex lane.
12. **W-038**, the `petitio` verb. The same absent-verb class as W-062, one
    artifact over; every cascade produces at least one petitio and the
    brief is written and bounded. It ranks behind W-062 only because
    petitiones are written once at the start and never amended, so the
    hand-edit pressure is lower.
13. **W-040**, gate correction (`ready --correct`). Real and append-only,
    but rarely hit, and W-062 narrows it to the gate signature alone — so
    it is cheaper after W-062 than before it, and waiting costs nothing.
14. **W-045**, record resilience: degrade per corrupt record, atomic
    front-matter writes. One corrupt record should not blind `check` to the
    whole officina — but there has still been no incident, and every writer
    now goes through one merge seam, so the exposure is smaller than when
    this was filed.
15. **W-052**, `run --opus` feeds `merge`. A documented path is genuinely
    broken (a builder's commits never reach `opus/<id>`); it stays
    mid-slate only because the operated flow uses `branch` plus raw git and
    so nobody is walking into it.
16. **W-032**, the PR gate. `gh pr create` is still the one lifecycle step
    nothing can refuse, but the required `gates` and `officina` checks
    already catch most of what it would refuse — its remaining value is
    catching the ungated PR before a remote sees it, not after.
17. **W-043**, `addressed_by` stamped through the CLI. Same hand-bookkeeping
    class as W-038, lower frequency; W-060 above fixes the *reading* of
    that field, which is the half that is currently wrong.
18. **W-055**, `talk`'s timeline records the replying model, and a canary
    model can never fail it. Provenance about which model actually answered
    — the same honesty D-014 demands of a review gate — but the exposure is
    one field in a gitignored timeline.
19. **W-054**, a talked session can run `bisellium` (PATH reaches the vendor
    shell snapshot). A real capability gap for delegated sellae, with a
    known workaround; it becomes urgent the day a talked session is
    expected to write bookkeeping of its own.
20. **W-056**, spawn-map assertions are snapshot-based everywhere. Fixed
    offsets in `talk-boundary` will break on an unrelated edit and blame the
    wrong change; test-maintenance debt, real but self-announcing.
21. **W-051**, `branch`/`merge` respect the repo's default branch. Matters
    before the first adopter on `main`, not before — this repo is on
    `master` and no adopter exists.
22. **W-053**, `run --reclaim` and `prune` see every worktree, the harness's
    included. Hygiene: stale worktrees cost disk, not correctness, and the
    cleanup wants an unsandboxed shell anyway.
