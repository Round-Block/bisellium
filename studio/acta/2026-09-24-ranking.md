# Slate ranking, 2026-09-24

This acta is the source of record for the order of the slate until a later
ranking acta replaces it. The backlog page (W-041) shows the inputs to
this ranking: state, blockers and gates. It does not rank. This order was
judged against the records as they stood on 2026-09-24. The working mode
is one serial Claude stream at a time, with codex lanes running in
parallel alongside it (D-020).

## Order

1. **W-041**, the generated backlog page. It is in flight (greenlit). It
   replaces the three hand-written rankings in the handoff with this acta
   and a generated page, and guards against them coming back.
2. **W-049**, harness env scrub. This is a security issue: an ambient
   base-URL or auth override can reach a spawned session. It jumps the
   queue the way W-044 did, and it carries W-044's round-4 advisories
   A1/A2 and the smoke test's leftover allow-half.
3. **W-039**, red logs name their sella. Without this, a red cannot be
   traced to whoever recorded it, which is an evidence-integrity gap. The
   brief is written and the scope is bounded.
4. **W-047**, contract test for `safeItemPath`. The traversal class failed
   round 1 on two opera in a row (W-042, W-044). One contract test closes
   the class once instead of each review catching it again. The brief is
   still a stub.
5. **W-046**, provider portability. It is the largest item, but running
   one opus end-to-end on both harnesses is what lets bounded work leave
   the Claude stream (throttle order, D-020). It carries the codex
   transport lessons. The brief is still a stub.
6. **W-038**, a petitio verb. Governance asks are still written by hand
   (D-021 notes the same gap for decisions). The brief is written.
7. **W-052**, the `run --opus` → `merge` chain. A builder's commits never
   reach `opus/<id>`. This is dormant only because the operated flow uses
   `branch` plus raw git instead of `run --opus`. It is a real break in a
   documented path.
8. **W-032**, the PR gate. `gh pr create` is the last lifecycle step
   nothing can refuse. The brief is written. It ranks behind W-052 because
   the required `gates` and `officina` checks already catch most of what it
   would refuse.
9. **W-040**, gate correction. There is no way today to re-sign a
   wrongly-signed gate without erasing its history. The brief is written,
   and it is rarely hit.
10. **W-045**, record resilience. One corrupt record should degrade only
    itself, and front-matter writes should be atomic. No incident yet, so
    it ranks mid-slate.
11. **W-043**, `addressed_by` through the CLI. This is the same
    hand-bookkeeping class as W-038 and follows it naturally. It is
    low-frequency.
12. **W-051**, respecting the repo's default branch. It only affects
    adopters, since this repo is on `master`. It matters before the first
    adopter on `main`, not before.
13. **W-048**, reds must be repo-runnable. This is an advisory rule. The
    codex-build trial attached to it is proposed but not decreed, so its
    slot depends on the Patron.
14. **W-053**, reclaim and prune should see the harness's worktrees. This
    is hygiene. Stale worktrees cost disk, not correctness, and the cleanup
    needs an unsandboxed shell anyway.

**Outside the serial order:** **W-050**, `bisellium ci` in the docs. It is
a docs-only template edit plus a regenerated CLAUDE.md, bounded and
clerk-shaped, so it is a codex-lane candidate that can run in parallel at
any time without taking a Claude slot.
