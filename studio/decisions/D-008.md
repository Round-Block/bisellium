Adopted alone by the Censor as an advisory detection rule
(`path.id.unvalidated`, advise): any id originating outside the manifest —
a hook payload `session_id`, `--kind`, an opus or sella id read from a file —
that is joined into a write path must pass the `manifest.id.format`
validator first, and any containment assertion must compare
`resolve(base, p)` against `base` by path relation, never by `startsWith`.

Evidence: lessons/L-004.md (cascade 4: receipts written outside the officina
from a hook payload; static containment by `startsWith`), lessons/L-011.md
(cascade 3: two builders joined ids into paths independently). Advisory, not
blocking — the promotion to blocking is asked for in petitiones/P-001.md,
clause 4, because it is not mine to make blocking alone.
