on a new edge of one lexical grammar (`studio/ci/W-178-review-1..3.log` on `opus/W-178`: comments, a cross-paired line,

still blocked on any wrong behaviour, however implausible the input. The Patron chose to fix that and let W-178's
running fix round finish.

## Decree

A. **A build review round blocks only on an S1 real defect** (wrong behaviour on an input this studio's or
   `examples/sample-studio`'s configuration plausibly produces, which no test catches), a security gap, or missing or
   false evidence. Wrong behaviour only on an input nothing here plausibly produces is an advisory naming the input and
   the test that would pin it; the builder may adopt it. Findings carry `[severity: S1|S2|S3|S4]`.
B. **Where it lives:** `studio/prompts/build-review.md` (round 1) and `studio/prompts/later-round.md` (every later round,
   which resumes the reviewer's session), both read from the main checkout; lex §9 step 4.
C. **It governs from W-178's build review round 4**, once this lands on master.
