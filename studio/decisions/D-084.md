## Decree

A. **A build review round blocks only on wrong behaviour on an input inside the brief's stated domain** (a form its
   grammar or Input domain lists, or an ordinary mistake in one: a stray comment, a typo, a dirty tree, mismatched
   flags; absence from today's files is not evidence against it), a security gap (anything touching tickets,
   authorisation, the sandbox or record writes), or missing or false evidence. Wrong behaviour on a form the brief's
   limits exclude or do not list is an advisory naming the form and the test that would pin it, which the architect may
   add as a limit or a ruled case. The later-round sibling hunt is bounded the same way. Findings carry
   `[severity: S1|S2|S3|S4]`.
B. **Where it lives:** `studio/prompts/build-review.md` (round 1) and `studio/prompts/later-round.md` (every later round,
   which resumes the reviewer's session), both read from the main checkout; lex §9 step 4.
C. **It governs from W-178's build review round 4**, once this lands on master.
