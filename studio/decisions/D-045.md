## Decree

1. **Evasion-only findings are advisory.** A review finding that names no
   instance in the code and only shows that a check or guard could be
   deliberately evaded (reflection, prototype-chain recovery, `eval`, alias
   gymnastics) is advisory, not blocking. The threat model is mistakes, not
   adversaries. A real instance in the code, or a security gap reachable by
   ordinary input, stays blocking.
2. **One receipt per opus, not per round.** Fix rounds are reviewed on the
   builder's gates plus one full `npm test` log on the reviewed head. The run
   receipt is minted once, after the passing review (and after any rebase the
   pr step needs), before the PR. A receipt that fails then reopens review.
