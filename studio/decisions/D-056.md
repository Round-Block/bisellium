Hand-written: there is still no `decide` verb (W-157). The Patron, 2026-10-10, after W-203's spec took
four Codex reviews (signature and review rounds numbered to 8) for a small CI change, most blockers being
form (a `catch` that is not a function name, a test row missing one read, "always" where a step is
skipped on push): "Round 8 is crazy", then "Yes" to the producer's proposal.

## Decree

1. **Blocking means substance.** Under D-046's two questions, a finding blocks only when the code path it
   names really accepts out-of-domain input without refusing (fails open), or a promise of the brief is
   actually false as written.
2. **Form is advisory.** A rejector the brief names imprecisely, or a row that omits an input whose path
   already fails closed, is advisory: the builder or the build review fixes it; it never fails a spec round.
3. **Applies at once** through `studio/prompts/spec-review.md`; W-196 moves the form checks into brief
   admission so they are caught before signing. Amends D-046 §1's "a finding on either blocks".
