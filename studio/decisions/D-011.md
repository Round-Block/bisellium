title: "A file that duplicates data the manifest or docs already hold is rendered, and its drift is detected"
at: 2026-09-18T20:00:00Z
provenance: observed
by: qa-lead
kill_when: "a rendered file is shown to need hand edits the renderer cannot express, or the drift rule produces a false positive with no correct action available"
---

Adopted alone by the Censor as an advisory detection rule
(`generated.stale`, advise): where a file restates data that lives in
`bisellium.yml`, `docs/ADOPTION.md` or a shared template, it is produced by
a command and compared against its source. Applies today to `CLAUDE.md`,
`AGENTS.md`, `GLOSSARY.md`, `.claude/agents/*.md` and `.claude/settings.json`
against `packages/shim/src/hooks/claude-code.json`.

Evidence: lessons/L-002.md (cascade 4b: three hand-maintained copies, each
drifting the day it was written — settings.json timeouts and quoting,
GLOSSARY's hardcoded VOCABULARY array, architect.md still naming eng-lead
after the Design collegium landed), lessons/L-009.md (cascade 1b: the Latin
rename by hand at ~361k tokens). This is D-005 applied to the maintenance of
a file rather than to a one-off bulk change. Note the known false positive to
avoid: `instructions.stale` must be gated on the officina the repo-root files
were actually rendered from, or `examples/sample-studio` advises forever.
