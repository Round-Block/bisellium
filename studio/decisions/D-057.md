## Decree

1. **Drafts ahead.** Codex drafts the next opera's specs at any time.
2. **Sign and review ahead only without overlap.** The architect signs, and the spec review runs, ahead of
   the queue only when the opus's Files owned overlap no opus in flight (branch, ready, build, review or
   merge). Work ahead happens in a scratch worktree off master, never in the main checkout while it is in use.
3. **Re-review what changed.** Before `branch`, any Files owned path that changed on master since the
   signature gets a spec-review round limited to that change (W-169's overlap check may enforce it).
4. **Enforcement.** The producer applies it by hand until a check rule or `next` refusal does; W-169 is
   the likely home.
