## Decree

1. **Changed code: full table.** D-046 question (a) applies in full to every reader the opus adds or
   changes: each record it reads, its valid domain and a real rejecting function that fails closed.
2. **Reused code: its exit.** Code the opus runs but does not change (a reused command, script or
   subprocess) is one input. Its row names the call and the function that turns a non-zero exit into a
   refusal. Reads inside it are not findings under (a). For a GitHub Actions step, that function is the
   runner's own step failure: a step with no `continue-on-error` that exits non-zero fails its job, and the
   job is a required check; the row names the step and that absence. An existing job the opus runs
   unchanged (for example under a new trigger) is one input: one row per job, naming its steps' shared rule
   and any context value that differs under the new trigger.
3. **Promises still hold.** Question (b) is unchanged: a promise the brief makes about reused code must
   still be guaranteed by its exit, or state its limit.
