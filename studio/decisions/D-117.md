## Ruling

Until W-419 lands, a fix round's new test cases may rest on their failing run against the pre-fix code, kept as evidence by the builder and committed beside the opus's other logs. A build reviewer does not block on the absence of a recorded `bisellium red` for them. The reviewer still blocks if that kept run does not fail by assertion on the new cases at the pre-fix commit, or if it is missing. This applies to W-417's fix round 1 and to any fix round before W-419 lands.
