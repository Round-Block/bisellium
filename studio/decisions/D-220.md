## Context

The Patron's idea (11-16): review gates (verdict/check/merge) refuse unless signed by a host-side
key, since a sandboxed session cannot be trusted to sign its own review outcome. The leads' meet
named a recommendation for each open call; the Patron ruled on four of them and left two standing
defaults unreopened.

## Ruling

1. Signer form: a host queue worker (systemd --user unit, or cron where systemd is off in WSL),
   run from the Patron's own clone at master, installed beside the hook guard; never a hook
   (timeouts, fires on agent events). An agent writes only `{opus, kind/phase, round, commit}` to
   a spool; the signer fetches the commit itself, builds the packet with master's
   review-packet.mjs and master's studio/prompts/, runs the review on a clean checkout, parses the
   outcome itself, and writes the verdict and signed record to a host-owned directory agents can
   read but not write.
2. Codex auth: a signer-only `CODEX_HOME` that no session can write; the Patron logs in there
   once. Today's shared `~/.codex` stays off the signer's path (it is sandbox-writable and unsound
   for this use).
3. Scope: every review gate, in two steps — Codex now (build and spec review verdict/check/merge);
   Claude Opus UI reviews (D-150 C) next, via a host `claude -p`, once that step is built. The UI
   gate stays unsigned, a stated limit, until the second step lands.
4. Trust root: the Patron code-owns the signer, verifier and packet-builder paths. Today's gap:
   these are agent-writable repo code, so a weakening PR would pass ordinary review unless
   code-owned.
5. Standing defaults, not reopened (3/3 leads' default, unasked of the Patron):
   a. a separate unattended gate key with its own domain line, never W-666's Patron receipt key
      (an unattended signer holding that key could forge Patron answers); public half in
      `studio/bisellium.yml` under its own code-owned key list.
   b. old unsigned gate records are grandfathered by a floor digest at the install commit; any
      opus with an open review round in flight at install re-runs that round under the signer.
