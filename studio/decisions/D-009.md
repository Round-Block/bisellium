Adopted alone by the Censor as an advisory detection rule
(`write.unredacted`, advise): content that did not originate in this repo —
a model reply, a child process's output, a hook payload, or manifest text
rendered into an instruction file — passes `redact()` and a
newline-strip/length-clamp before it lands in any tracked file, not just in
`receipts/` and `ci/*.log` where docs/ADOPTION.md already requires it.

Evidence: lessons/L-005.md (cascade 4b: a manifest id rendered a forged
`## Standing rules` heading into CLAUDE.md), lessons/L-013.md (cascade 3: a
model reply written unredacted into a tracked acta), lessons/L-012.md
(cascade 2: unredacted receipts). The boundary was identified once and then
defended only at the two call sites where it was first found.
