## Decree

1. **No check is removed, only repeats.** Every certificate the studio records is still produced once, on
   the tree that reaches master (production lex §11, no shortcuts in CI or tests).
2. **CI once per merge (W-205).** The full gates run in the merge queue's `merge_group` run, which
   certifies the merge result; the `pull_request` run no longer repeats it. A `.github/` change: the
   Patron approves the PR as code owner (W-197).
3. **The spec rides in the opus's PR (W-206).** The spec review still passes before the build starts.
4. **Verify reuses the queue's certificate (W-207)** when it certified the tree master holds.
5. **Spec review judges what the change touches.** Under question (a), a read on a line the opus does
   not change is reused, unchanged code (D-050), even inside a function the opus changes: it is not a
   finding, unless a promise of the brief depends on it, which question (b) still judges. Effective at
   once: `studio/prompts/spec-review.md` carries the clause. Amends D-050's scope.
