vs what is for agents only"; "yes record it".

## Decree

1. **Audience is data.** Every opus carries `audience: console | agent | both`,
   set through a verb like milestone and value, never by hand. `console` is
   what the Patron sees or does; `agent` is machinery only agents use (the
   ladder, check rules, receipts, evidence); `both` is a capability with a
   Patron-facing console path and agent-facing machinery.
2. **The end-state rule.** Anything the Patron is expected to do has a
   console path in the end state; chat with the orchestrator is a stopgap
   that ends there. Agent machinery never requires the Patron to touch it.
3. **The Status page splits by audience**: the backlog and the completion
   meter can be read for the console alone.
4. **The first sort** of the open opera is proposed by a lower-tier model,
   checked by the producer, and only the unclear ones go to the Patron.

The field, its verb, its check and the Status page split are one opus,
filed with this decision.
