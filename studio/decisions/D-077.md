A. **No store outside git for work state** (D-074 A's line): the queue, records and handoff stay git records; only locks,
   tickets and markers live under `.bisellium/`.
B. **The tracker** is `studio/queue.yml` plus each opus's record and traditio, read through a read-only `next --all`.
   W-299 absorbs W-247 (the handoff Resume point and its required edit go) and `next --all`; W-247 is halted as absorbed.
   The handoff keeps standing instructions only. The out-of-repo session note is retired: a fresh session boots from the
   handoff and `next`.
C. **The timeline** (W-308): `greenlight` writes `greenlit_at`; the branch and merge performs record their ticket line as
   ready, review and done do; the done perform copies the PR's created and merged times; a read-only
   `next <id> --timeline` prints the rows and minutes (`--all` lists them). It retires the hand-run `elapsed.mjs` and the
   reconstruction in `retro.py`; the daily retro (D-076 F) reads it. W-300 shows it in the Board drawer.
D. **No OTel or Grafana now.** The wire names are already OTel-style (D-004); an OTLP exporter is a backlog note.
