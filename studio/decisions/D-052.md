## Decree

1. **A collegium of its own.** Chaos (id `chaos`, magister `chaos-lead`; first proposed as Naumachiae,
   renamed plain to match the other collegia) gets its own lex, magister, budget and cadence, and runs separately from engineering and UI development: it never
   blocks an opus in flight and files what it breaks as opera.
2. **Wide scope.** It attacks the code (mutation tests on recent changes), the run (a step killed
   mid-flight, corrupt records, failing `git`/`gh`), the environment (the real sandbox, read-only
   paths), the gates (a deliberately bad change against review, CI and the queue; concurrent lanes and
   races) and the inputs (fuzzing the record loaders).
3. **One inline check.** The mutation check on a PR's changed lines also gates its build review, so weak
   tests cannot merge.
4. **Enforcement.** W-200 sets up the collegium; W-201 builds the inline mutation check. Both are check
   rules or verbs, never prose.
