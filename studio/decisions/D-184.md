1. One storage opus, W-520 if that id is free, is exempt from D-178's freeze and runs after W-456 and W-519. It takes over W-380, whose "small text only" rule is dropped: nothing is dropped by size.
2. Staging copies go under `$TMPDIR`, outside the evidence folder. The outermost runner deletes them on exit, not `stages.sh`, as later steps use the copy after it returns. Diffs and bundles are saved first.
3. A finished opus's evidence is compressed: the original stays until a tested archive and a manifest of name, size and sha256 exist, and an index leaves cited paths resolvable. Session logs, reds, verdicts and screenshots are kept, compressed.
4. `tick` reports any evidence folder over a size limit. It only reports.
5. The test for clearing a temporary copy. All must hold; any read that fails means keep and log.
   (a) It is a git clone of a kept prototype repository in a temporary folder a script created; a name alone is not enough.
   (b) Its opus, read through the CLI, is done; never for greenlit, building, review, verifying, halted, deferred, held or parked; a copy whose opus has no record must be over 2 days old.
   (c) No uncommitted or untracked files, no stash, and every commit in a kept repository; otherwise the diff, a commit bundle and a tar of untracked files are saved first, and if that save fails the copy stays whole.
   (d) No change for at least a day, and no run holds a lock on it. The lock is the producer's, replacing the leads' live-process check. Ignored files other than `node_modules` are saved or their names recorded.
6. Never cleared by this test: worktrees, named output folders, kept prototype repositories and evidence files.
7. `prune-scratch.sh` deletes by name and is not to be used until it applies this test.
8. The backup stays on this machine for now, so the evidence remains on one disk, which the Patron accepts for now.
