## Goal, measure, stop rule

**Goal.** An ordinary opus runs greenlight to done with the orchestrator making decisions, not recalling flag shapes: no
hand-run evidence scripts, no hand-edited handoff prose, no verdicts copied by hand, no orchestrator-chat record writes.
The console then renders the same functions (`serve.ts` injects them), so it gets cheaper, not a second implementation.

**Measure.** Orchestrator shell calls between greenlight and done, counted from the session transcript (the PostToolUse
logger matches `Write|Edit` only, so Bash calls are not in it; W-292's `.claude/` change may widen the matcher). Baseline
about 25 on W-293; target under 8.

**Stop rule.** The block ends, and the console MVP starts, when two consecutive opera pass the trial: zero hand-run
evidence scripts, zero required handoff edits, review independence kept, and a safe restart after an interruption, with
one failed review and one interrupted run between them. It stops early, and the queue is re-ranked, if the count has not
fallen below 15 after W-214, W-274 and W-292 are done, or at two calendar weeks, whichever comes first.
