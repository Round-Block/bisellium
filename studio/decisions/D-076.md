## Why

Of 57 blocking findings in 20 failed review rounds, about 8 were real (5 defects, 2 product-real, 1 security); 14 of the
20 failed rounds blocked only on wording or theory. That cost about 20 minutes per opus, about 1% of cycle time; Patron
wait, one-lane queueing and verify reruns dominate. The cause-fix opera filed for recurring wording classes (W-303,
W-306, W-307) police prose; only W-264 fixed code, and W-274 failed 8 blockers despite carrying every ledger.

## Decree

A. **Severity.** Each finding carries `[severity: S1|S2|S3|S4]`: S1 a real defect (a plausible mistake in this studio's
   or examples/sample-studio's configuration makes the code fail open or wrong, and no existing test catches it); S2 a
   false promise only (the code is fine, a sentence over-promises); S3 theoretical (an unlikely or deliberate input,
   D-045); S4 a wording or test-boundary nit. **Only S1, a security gap, or missing or false required evidence block.**
   S2 and S4 are advisories with replacement text, which the builder adopts in the build; the build review's prose check
   is the one place promise wording is judged. S3 is noted.
B. **Spec rounds.** A spec gets a second review only when the first found an S1 that changes the design; an S1 that does
   not change the design becomes a required build fix with its own red. The two-round cap stays the ceiling; adopted
   replacement text counts as signed.
C. **Prompt.** The spec-review prompt's completeness sweep ("this review should be the last one"; every "never",
   "always" and "every") is removed; the two D-046 questions stay.
D. **Cause fixes (narrows D-070 C).** A greenlit cause-fix opus is filed only when an S1 class recurs; wording classes
   recur as advisories. W-307 is halted. W-306 stays; its ledger check becomes a warning if the next two opera still fail
   on promise wording.
E. **Architect.** Unchanged code gets a stated limit, not a guarantee; no length rule for briefs.
F. **Daily retro and tracker.** Once a day the producer runs the daily retro
   (`~/.bisellium-evidence/retro-daily/retro.py`): per opus done that day, cycle minutes, Patron wait, failed rounds and
   blockers by severity; it updates `studio/acta/improvements.md`, the tracker of every process change since 2026-10-16
   with its expected and measured saving. Each checkpoint row adds the S1 count per failed round.
