  blesses UI briefs' design content (layout, interaction, screen
  decomposition against the canvas), and answers UI open items that briefs
  would otherwise route to the Patron — within the canvas. The Patron's
  canvas designs and recorded decrees (side panel, DIRECTION.md
  2026-09-24) remain the layout authority; the ui-lead interprets them,
  never overrides them.
- **Red-teams UI briefs** in the Sol slot for UI opera (a UI-specialised
  red-team is worth more there than a general one; Sol remains the
  red-teamer for non-UI opera).
