Decreed 2026-09-23 (Patron): Codex worker models join the studio's worker
pool, spread across task types.

### Producer's implementation mapping

Provenance of this section: **producer-proposed under the decree above**,
not itself decreed — revisable by the producer without a new decision, so
long as it stays inside the hard boundaries below.

- **gpt-5.6-luna** (fast tier) — bounded clerk-shaped work: doc/table
  aggregation, sweeps, fixture checks, provenance greps, progress rows.
  First live assignment: checkpoint-24 progress rows.
- **gpt-5.6-terra** (mid tier) — mechanical audits, golden-table
  generation, CI log triage, lesson drafting from recorded evidence,
  cross-checks of builder claims that feed the censor (never replacing
  it).
- **gpt-5.6-sol** (high tier) — research memos, threat-model and analysis
  input to architect specs, second-opinion analysis on demand.

### Hard boundaries the decree does not move

- The review gate remains the Opus-tier censor alone (D-014, as amended
  2026-09-23 to tier pin). Codex models sign no gates and record no
  verdicts.
- Opus builds remain Sonnet-tier builders (D-014).
- Codex models write no officina bookkeeping except through the CLI, like
  every other worker.

### Transport

`codex exec -c model_provider=openai` — OpenAI direct; tokenharbor env is
key-storage convenience only. Sandboxed via the `.claude/settings.local.json`
allowances of 2026-09-23.

Dispatch integration through the studio's own machinery (model passed to
the harness, command policy for codex) is W-046's scope. Until it lands,
codex dispatches are orchestrator-mediated `codex exec` calls — an interim
clause, not the target shape.

kill_when fires on either event: W-046 landing retires the interim
transport clause along with it (dispatch moves into the CLI proper); or a
codex-tier worker producing evidence a gate relied on without the censor
re-verifying it — either triggers a review of this decision.

Amended 2026-09-23 (Patron): **gpt-6-astra joins as the escalation tier** —
invoked only on the named triggers from the Astra role policy (unresolved
spec/architecture ambiguity, cross-discipline planning, conflicting
evidence, repeated failed repairs); output is input to the architect or
the Patron, never orchestration, never a gate; the one-active-orchestrator
rule stands. First assignment: an independent take on W-033 (bookkeeping
provenance), adjudicated against the architect's. Same hard boundaries as
the other codex tiers.

Model releases move fast enough that tier mappings in this decision are
expected to churn: any model name above is read as "current holder of
that tier," per D-014's amendment, and a major release on either
provider's side is reason to revisit the mapping without a new decree.

Amended 2026-09-24 (Patron): two standing pipeline slots join the
mapping. **Terra pre-review verification** — every censor round is
preceded by a gpt-5.6-terra pass that mechanically verifies the builder's
claims (gates re-run, diff scope, red reproduction, certificate
recomputation) and hands the censor a verified evidence sheet; the censor
keeps sole judgment (D-014 untouched). **Sol brief red-team** — before
the spec gate is signed on a security-touching or cross-cutting opus,
gpt-5.6-sol reads the architect's brief hunting for untestable phrasing,
unenumerated classes, and acceptance criteria a stub could satisfy;
output is input to the architect, who owns the spec. Evidence for both:
W-042's and W-044's round-1 blocking defects each traced to brief
wording the censor caught only at review price. A Sol pass on PASS
verdicts is deliberately NOT added — it would edge toward a second gate;
if ever wanted it belongs at retro time, feeding lessons, never blocking
merges.

Amended 2026-09-24 (Patron, "we can push codex harder"): **a one-opus
codex-build trial** — W-050 (`bisellium ci` docs, docs-only) is built by
gpt-5.6-sol instead of a Sonnet builder. Everything else in the pipeline
is unchanged and unwaived: architect spec, Sol brief red-team, Terra
pre-review, and the Opus-tier censor as the sole judge — the censor's
normal verdict IS the trial's benchmark. This amends D-014's builder-tier
clause for this one named opus only; a second codex build requires the
trial's recorded outcome plus a fresh decree. If the trial's review round
count exceeds the current Sonnet median (2), the trial reads as a fail
regardless of eventual merge.
