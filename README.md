# Atrium (working name)

An agent organization modeled on a product studio — departments, budgets,
delegation, a slate — for any project. Gantry is its console; epoch0 is the
reference instance (observed, never modified from here).

## The one idea

A department is **charter + budget + digest**: a written scope of what its lead
decides alone, a token/time allowance per period, and an obligation to report by
digest and escalate only by exception. Everything else in a studio is built from
that unit.
